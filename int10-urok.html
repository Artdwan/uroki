Функции y = [x], y = {x} и их свойства

Алгебра · 10 класс · §4 · теория порциями, 12 разобранных примеров и 27 заданий с решениями
Как работать. Читаем порцию теории, разбираем пример, затем решаем задания блока в тетради — и только потом открываем решение и сверяемся.
Главная мысль темы: целая часть — это шаг влево по числовой прямой, а не отбрасывание хвоста. Всё остальное — следствие этого правила.
В построении графиков решает одно: где стоят скобки. Снаружи — округляем значение и проводим горизонтальные прямые. Внутри — округляем аргумент и проводим вертикальные.
Тренажёров и отправки работы здесь нет: это урок.

1. Целая часть числа

ОПРЕДЕЛЕНИЕ
Целой частью числа называется наибольшее целое число, не превосходящее данное число.

Обозначают [a], читают «целая часть числа a» или «антье от a» (от французского antier — целый).

ГЛАВНАЯ ЛОВУШКА ТЕМЫ
[a] — это не «отбросить всё после запятой». Это шаг влево по числовой прямой до ближайшего целого. У положительных чисел разницы не видно, а у отрицательных она решает всё.
[2,3] = 2,   [−3,4] = −4

Почему [−3,4] равно −4, а не −3? Потому что −3 больше, чем −3,4, а целая часть не имеет права превосходить само число. Ближайшее целое слева — это −4.

Пример 1

числососедние целыецелая часть
2,32 < 2,3 < 3[2,3] = 2
−3,4−4 < −3,4 < −3[−3,4] = −4
5число уже целое[5] = 5
−5число уже целое[−5] = −5
Работает одно правило: найди на числовой прямой ближайшее целое слева (или само число, если оно целое).

Отбрасывание хвоста работает только для неотрицательных чисел.

2. Функция y = [x] и её свойства

Каждому действительному числу отвечает ровно одна целая часть, поэтому на множестве всех действительных чисел определена функция y = [x].

  1. Область определения: D([x]) = R — целую часть можно взять у любого числа.
  2. Множество значений: E([x]) = Z — по определению целой части результат всегда целый.
  3. Нули функции: x ∈ [0; 1), потому что целая часть любого числа от 0 до 1 равна нулю.
  4. Промежутки знакопостоянства: y > 0 при x ∈ [1; +∞),  y < 0 при x ∈ (−∞; 0).
  5. Функция не убывающая: если x₁ > x₂, то [x₁] ≥ [x₂] — график либо стоит на месте, либо поднимается.
  6. Если n ≤ x < n + 1 и n ∈ Z, то [x] = n.
КАК ЧИТАТЬ ГРАФИК
Это лесенка из горизонтальных отрезков длиной 1. Левый конец каждой ступеньки закрашен — точка входит в график, правый выколот — не входит. Поэтому в каждой целой точке у функции «скачок» ровно на единицу.

3. Дробная часть числа

ОПРЕДЕЛЕНИЕ
Дробной частью числа a называется разность между числом a и его целой частью: {a} = a − [a].
{2,4} = 2,4 − 2 = 0,4   {−2,4} = −2,4 − (−3) = 0,6
СЛЕДСТВИЕ ИЗ ЛОВУШКИ
У отрицательных чисел дробная часть — это не «цифры после запятой». Раз целая часть ушла влево, разность получается больше: {−2,4} = 0,6, а вовсе не 0,4. Проверить легко: дробная часть никогда не бывает отрицательной и всегда меньше единицы.

Пример 2

числоцелая частьдробная часть
2,4[2,4] = 2{2,4} = 0,4
−2,4[−2,4] = −3{−2,4} = 0,6
7[7] = 7{7} = 0
−0,3[−0,3] = −1{−0,3} = 0,7
Подсказка для проверки: сумма целой и дробной частей всегда возвращает исходное число.

4. Функция y = {x} и её свойства

Дробная часть тоже определена для любого числа, поэтому на всей числовой прямой задана функция y = {x}.

  1. Область определения: D({x}) = R.
  2. Множество значений: E({x}) = [0; 1) — по определению дробной части.
  3. Нули функции: x = n, n ∈ Z — дробная часть целого числа равна нулю.
  4. Знакопостоянство: {x} > 0 для всех действительных чисел, кроме целых.
  5. Функция возрастает на каждом из промежутков [n; n + 1).
  6. Если n ∈ Z, то {n} = 0.
  7. Функция периодическая с наименьшим положительным периодом 1, так как {x} = {x + 1}.
КАК ЧИТАТЬ ГРАФИК
Это пила: один и тот же наклонный отрезок от 0 до 1, повторённый с периодом 1. Левый конец каждого зубца закрашен (значение 0 достигается), верхний правый — выколот: единицы функция не достигает никогда.

Задание 12 · доказательство

2. Тогда {x + 1} = (x + 1) − ([x] + 1) = x − [x] = {x}.
3. Если бы период T был меньше 1, то на промежутке [0; 1) нашлись бы два разных значения аргумента с одинаковой дробной частью — а там функция строго возрастает.
Период равен 1, и меньшего положительного периода нет

5. Строим график y = [f(x)]

АЛГОРИТМ
  1. Построить график функции y = f(x).
  2. Провести прямые y = n, n ∈ Z.
  3. Отметить точки пересечения этих прямых с графиком y = f(x). Каждую часть графика между прямыми y = n и y = n + 1 заменить её проекцией на прямую y = n.

Смысл простой: внешние скобки округляют значение функции вниз до целого. Значит весь график «оседает» на ближайшую снизу горизонтальную прямую с целым y.

Пример 3. y = [x²]

1. Строим параболу y = x2.
2. Проводим прямые y = n и смотрим, между какими из них проходит парабола.
3. Каждый кусок опускаем на нижнюю прямую — получается лесенка из горизонтальных отрезков.
Чем дальше от нуля, тем быстрее растёт парабола — и тем короче становятся ступеньки.

Пример 4. y = [1x]

1. Строим гиперболу y = 1x.
2. При x > 1 гипербола лежит между 0 и 1, поэтому там y = 0.
3. Ближе к нулю значения растут, и ступеньки становятся всё уже.
В точке x = 0 функция не определена — там у гиперболы разрыв.

6. Строим график y = f([x])

АЛГОРИТМ
  1. Построить график функции y = f(x).
  2. Провести прямые x = n, n ∈ Z.
  3. Отметить точки пересечения этих прямых с графиком. Каждую часть графика между прямыми x = n и x = n + 1 заменить её проекцией на прямую y = f(n).
В ЧЁМ ОТЛИЧИЕ ОТ ПРЕДЫДУЩЕГО
Здесь скобки стоят внутри: округляется не значение, а аргумент. Поэтому прямые проводят вертикальные, а ступеньки получают ту высоту, которую функция имеет в левом конце каждого промежутка.

Пример 5. y = [x]2

1. Строим параболу y = x2.
2. Проводим вертикальные прямые x = n.
3. На промежутке [n; n + 1) аргумент округляется до n, значит значение постоянно и равно n2.
Высоты ступенек — квадраты целых чисел: 0, 1, 4, 9 — поэтому лесенка растёт всё круче.

Пример 6. y = 1[x]

1. На промежутке [n; n + 1) значение равно 1n.
2. При x ∈ [0; 1) получается [x] = 0 — деление на нуль, функция не определена.
Функция не определена при x ∈ [0; 1)
Это главная особенность таких графиков: у них появляются целые промежутки, где функции просто нет.

7. Строим график y = {f(x)}

АЛГОРИТМ
  1. Построить график функции y = f(x).
  2. Провести прямые y = n, n ∈ Z.
  3. Часть графика между прямыми y = 0 и y = 1 оставить без изменений.
  4. Каждую часть графика между прямыми y = n и y = n + 1 перенести на |n| единиц вниз, если n > 0, или вверх, если n < 0.

Полученный график лежит в полосе между прямыми y = 0 и y = 1 и прямую y = 1 не пересекает — ведь дробная часть единицы не достигает.

Пример 7. y = {x2}

1. Строим параболу и режем её горизонтальными прямыми с целыми y.
2. Каждый кусок опускаем в полосу от 0 до 1.
3. Чем дальше от нуля, тем быстрее растёт парабола — тем чаще она пересекает прямые и тем уже получаются зубцы.
График симметричен относительно оси y, потому что x2 не различает знака.

Пример 8. y = {1x}

1. При x > 1 значение 1x лежит между 0 и 1, поэтому график совпадает с гиперболой.
2. Ближе к нулю гипербола пересекает всё больше целых уровней, и зубцы сгущаются.
Нарисовать все зубцы у нуля невозможно: их бесконечно много.

8. Строим график y = f({x})

АЛГОРИТМ
  1. Построить график функции y = f(x).
  2. Провести прямые x = n, n ∈ Z.
  3. Часть графика между прямыми x = 0 и x = 1 оставить без изменений.
  4. Каждую часть графика между прямыми x = n и x = n + 1 получить сдвигом куска, лежащего между x = 0 и x = 1, на |n| единиц вправо при n > 0 и влево при n < 0.
ГЛАВНОЕ СЛЕДСТВИЕ
Такой график всегда периодический с периодом 1: один и тот же кусок повторяется бесконечно в обе стороны. Достаточно построить его на промежутке [0; 1) и размножить.

Пример 9. y = 1{x}

1. На промежутке (0; 1) дробная часть совпадает с x, значит там график — обычная гипербола.
2. В целых точках {x} = 0 — деление на нуль, функции нет.
Не определена при целых x
Значения всегда больше 1: ведь {x} < 1.

Пример 10. y = {x}2

1. На промежутке [0; 1) получаем y = x2 — кусок параболы от 0 до 1.
2. Этот кусок повторяем вправо и влево через каждую единицу.
Сравни с примером 7: там были зубцы разной ширины, здесь — одинаковые.

y > 1, то есть E = (1; +∞)

Сравни графики y = {x2} и y = {x}2. Чем они отличаются?

2. y = {x}2: скобки внутри, дробную часть берём у аргумента. Получается один и тот же кусок параболы с периодом 1.

Оба лежат в полосе от 0 до 1, но устроены совершенно по-разному.

9. Ступеньки в жизни

Целая часть появляется всюду, где платят «за каждую начатую» единицу: минуту разговора, десять килограммов багажа, сутки аренды. График такой зависимости — всегда лесенка.

ПОЛНАЯ ИЛИ НЕПОЛНАЯ
Слова «за каждую полную или неполную минуту» означают округление вверх: за 1,2 минуты платят как за две. Через целую часть это записывают так: ⌈t⌉ = −[−t], а на практике проще считать по ступенькам.

Пример 11. Плата за багаж

За первые 30 кг — 20 рублей, а за каждые последующие полные или неполные 10 кг плата возрастает на 10 рублей.

1. До 30 кг включительно — ровно 20 рублей.
2. От 30 до 40 кг — 30 рублей, от 40 до 50 — 40 рублей, и так далее.
3. Каждая ступенька длиной 10 кг и высотой 10 рублей.
За 31 кг придётся заплатить столько же, сколько за 40: 30 рублей.

Пример 12. Стоимость звонка

Звонок стоит 1,5 рубля за каждую полную или неполную минуту разговора.

1. Разговор до одной минуты включительно — 1,5 рубля.
2. От одной до двух минут — 3 рубля, от двух до трёх — 4,5 рубля.
3. Высота каждой ступеньки 1,5 рубля, длина — одна минута.
Разговор в 61 секунду стоит вдвое дороже, чем в 59: ступенька уже переключилась.

Задание 25 · по графику
Сколько будет стоить перевозка багажа массой: 1) 28 кг;   2) 31 кг;   3) 50 кг;   4) 51 кг?
Показать решение
1. 28 кг — это в пределах первых тридцати: 20 рублей.
2. 31 кг — начались вторые десять килограммов: 20 + 10 = 30 рублей.
3. 50 кг — это ровно две полные десятки сверх тридцати: 20 + 20 = 40 рублей.
4. 51 кг — пошла третья десятка: 20 + 30 = 50 рублей.
20, 30, 40 и 50 рублей
Один лишний килограмм между 50 и 51 стоит десять рублей — в этом и состоит особенность ступенчатых тарифов.
Задание 26 · по графику
Сколько стоит разговор длительностью: 1) 1 минута;   2) 1 минута 12 секунд;   3) 3 минуты 30 секунд?
Показать решение
1. Ровно минута — одна полная минута: 1,5 рубля.
2. 1 минута 12 секунд — это вторая начатая минута: 2 · 1,5 = 3 рубля.
3. 3 минуты 30 секунд — четвёртая начатая минута: 4 · 1,5 = 6 рублей.
1,5; 3 и 6 рублей
Считаем не полные минуты, а начатые — поэтому 3,5 минуты оплачиваются как 4.
Задание 27 · со звёздочкой
Опиши, как выглядят графики функций: 1) y = [x8];   2) y = {x8};   3) y = [x]8;   4) y = {x}8.
Показать решение
1. y = [x8] — как y = [x2], но восьмая степень растёт куда быстрее: ступеньки сужаются почти сразу за |x| = 1.
2. y = {x8} — зубцы в полосе от 0 до 1, сгущающиеся ещё гуще, чем у {x2}.
3. y = [x]8 — ступеньки шириной 1 с высотами n8: 0, 1, 256, 6561 — график взлетает почти вертикально.
4. y = {x}8 — кусок параболоподобной кривой от 0 до 1, повторённый с периодом 1; он прижат к нулю почти на всём промежутке и резко взлетает к единице у правого конца.
Первые два — «внешние» скобки, вторые два — «внутренние»
Чётная степень всюду убирает знак, поэтому все четыре графика симметричны относительно оси y или периодичны.

Что забрать с урока

Два определения

Целая часть

Наибольшее целое, не превосходящее число.

[2,3] = 2,  [−3,4] = −4.

Это шаг влево по прямой, а не отбрасывание хвоста.

Дробная часть

{a} = a − [a].

{2,4} = 0,4,  {−2,4} = 0,6.

Всегда от 0 включительно до 1 не включительно.

Проверка ответа

Дробная часть не бывает отрицательной и не достигает единицы.

Сумма целой и дробной частей возвращает само число.

Две функции

y = [x]

D = R,  E = Z.

Лесенка из отрезков длиной 1, неубывающая.

Нули на [0; 1).

y = {x}

D = R,  E = [0; 1).

Пила с периодом 1, возрастает на каждом зубце.

Нули в целых точках.

Скобки снаружи и внутри

Снаружи — округляем значение, прямые горизонтальные.

Внутри — округляем аргумент, прямые вертикальные.

Внутренние скобки всегда дают период 1.

Построения

Четыре алгоритма

y = [f(x)] — проекции вниз на y = n.

y = {f(x)} — сдвиги в полосу от 0 до 1.

y = f([x]) и y = f({x}) — работа с вертикальными прямыми.

Где теряют область определения

y = 1/[x] не существует на всём [0; 1).

y = 1/{x} не существует в целых точках.

Ступеньки в жизни

«За каждую полную или неполную» — округление вверх.

График такой оплаты — лесенка.

Один лишний килограмм может стоить как целых десять.
