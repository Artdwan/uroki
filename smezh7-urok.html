Смежные и вертикальные углы. Перпендикулярные прямые

Геометрия · 7 класс · §6-§7 · пять теорем с доказательствами, два живых чертежа и 63 задания с решениями
Как работать. Читаем порцию теории, разбираем пример, затем решаем задания блока в тетради — и только потом открываем решение и сверяемся.
Вся тема держится на двух фактах: сумма смежных углов равна 180°, а вертикальные углы равны. Всё остальное — следствия.
Смежные и вертикальные определяются расположением сторон, а не тем, как углы выглядят на рисунке. Проверять надо по определению.
Тренажёров и отправки работы здесь нет: это урок.

Памятка

Три определения

Смежные углы

Одна сторона общая, две другие — дополнительные лучи, то есть продолжения друг друга.

∠1 + ∠2 = 180°

Вертикальные углы

Стороны одного угла — дополнительные лучи к сторонам другого.

∠1 = ∠2

Перпендикулярные прямые

Пересекаются под прямым углом; тогда все четыре угла по 90°.

a ⊥ b

Что из них следует

Какой угол смежный

С острым — тупой, с тупым — острый, с прямым — прямой.

Если смежные углы равны, каждый из них прямой.

Смежных у угла два

Продолжить можно любую из двух сторон, поэтому смежных с данным углом ровно два, и они вертикальны между собой.

Четыре угла при пересечении

Две пары равных: ∠1 = ∠3 и ∠2 = ∠4.

Сумма всех четырёх равна 360°. Достаточно знать один угол.

Техника счёта

Отношение и разность

Отношение m : n — это mx и nx, сумма (m + n)x = 180°.

Разность d: углы (180° + d) : 2 и (180° − d) : 2.

Биссектрисы

Биссектрисы смежных углов перпендикулярны.

Биссектрисы вертикальных углов лежат на одной прямой.

Перпендикуляр

Отрезок из точки к прямой под прямым углом. Его конец на прямой — основание, а длина — расстояние от точки до прямой.

Через любую точку перпендикуляр к данной прямой ровно один.

1. Смежные углы

ОПРЕДЕЛЕНИЕ
Два угла называются смежными, если у них одна сторона общая, а две другие являются дополнительными лучами.

Дополнительные лучи — это лучи одной прямой с общим началом, продолжения друг друга. На чертеже лучи OA и OB дополнительные, поэтому углы ∠AOC и ∠BOC смежные.

ТЕОРЕМА (свойство смежных углов)
Сумма смежных углов равна 180°.

Доказательство

Дано: ∠AOC и ∠BOC — смежные.
Доказать: ∠AOC + ∠BOC = 180°.
1. По определению смежных углов лучи OA и OB дополнительные, значит вместе они образуют развёрнутый угол ∠AOB, равный 180°.
2. Луч OC проходит между сторонами этого угла.
3. По аксиоме измерения углов ∠AOC + ∠BOC = ∠AOB = 180°.
что и требовалось доказать
ОБЩАЯ СТОРОНА — ЭТО ЕЩЁ НЕ ВСЁ
Два угла с общей стороной не обязаны быть смежными. Нужно, чтобы две другие стороны были именно дополнительными лучами, то есть лежали на одной прямой и шли в разные стороны.

2. Что следует из теоремы

СЛЕДСТВИЯ
1. Если смежные углы равны, то каждый из них прямой.
2. Если два угла равны, то равны и смежные с ними углы.

Почему это так

1. Пусть смежные углы равны и каждый равен x. Тогда x + x = 180°, значит x = 90°.
2. Пусть ∠1 = ∠2. Смежные с ними равны 180° − ∠1 и 180° − ∠2, а это одно и то же число.
КАКОЙ УГОЛ СМЕЖНЫЙ
С острым углом смежен тупой: если " + nw("∠1 < 90°") + ", то ∠2 = 180° − ∠1 > 90°.
С тупым смежен острый, а с прямым — прямой.
СМЕЖНЫХ У УГЛА ДВА
Продолжить можно любую из двух сторон, поэтому у каждого угла ровно два смежных с ним угла. Между собой эти два угла вертикальные, а значит равны.

3. Как считают смежные углы

Почти все задачи темы — это одно уравнение. Одну часть обозначают за x, вторую выражают через условие, а сумму приравнивают к 180°.

первый + второй = 180°

Пример 1. Отношение

Смежные углы относятся как 2 : 3. Найти величину каждого из них.

1. Пусть одна часть равна x. Тогда ∠1 = 2x, ∠2 = 3x.
2. 2x + 3x = 180°, то есть 5x = 180° и x = 36°.
3. ∠1 = 2 · 36° = 72°, ∠2 = 180° − 72° = 108°.
∠1 = 72° · ∠2 = 108°
Проверка: 72° + 108° = 180° — сумма сошлась.

Пример 2. Разность

Один из смежных углов на 40° больше другого. Найти оба угла.

1. Меньший x, больший x + 40°.
2. x + x + 40° = 180°, 2x = 140°, x = 70°.
меньший = 70° · больший = 110°
Короткая формула: меньший равен (180° − d) : 2, больший — (180° + d) : 2, где d — разность.

Пример 3. Во сколько раз и проценты

«В 3 раза больше»: x + 3x = 180°, x = 45°, углы 45° и 135°.
«На 40 % больше»: x + 1,4x = 180°, 2,4x = 180°, x = 75°, углы 75° и 105°.
«Составляет 20 % от второго»: 0,2y + y = 180°, y = 150°, углы 30° и 150°.
ГРАДУСЫ И МИНУТЫ
В одном градусе 60 минут. Чтобы найти смежный с 140°20′, занимают один градус: 180° = 179°60′, и тогда 179°60′ − 140°20′ = 39°40′.

4. Вертикальные углы

ОПРЕДЕЛЕНИЕ
Два угла называются вертикальными, если стороны одного угла являются дополнительными лучами к сторонам другого.

При пересечении двух прямых в точке O получается, что лучи OA и OC, а также OB и OD дополнительные. Поэтому углы ∠AOD и ∠BOC вертикальные; углы ∠AOB и ∠DOC тоже вертикальные.

ТЕОРЕМА (свойство вертикальных углов)
Вертикальные углы равны.

Доказательство

Дано: ∠1 и ∠2 — вертикальные.
Доказать: ∠1 = ∠2.
1. Возьмём угол ∠3, соседний с обоими. Углы ∠1 и ∠3 смежные, потому что по определению вертикальных углов соответствующие лучи дополнительные.
2. По свойству смежных углов ∠1 + ∠3 = 180°.
3. Углы ∠2 и ∠3 тоже смежные, значит ∠2 + ∠3 = 180°.
4. Тогда ∠1 = 180° − ∠3 и ∠2 = 180° − ∠3, то есть ∠1 = ∠2.
что и требовалось доказать
Вся суть: два угла, смежные с одним и тем же углом, равны между собой.

5. Четыре угла при пересечении

При пересечении двух прямых образуются четыре угла, не считая развёрнутых. Среди них две пары равных — вертикальные, а любые два соседних — смежные.

∠1 = ∠3, ∠2 = ∠4, ∠1 + ∠2 = 180°

Поэтому достаточно знать один угол: остальные три находятся сразу.

УГОЛ МЕЖДУ ПРЯМЫМИ
Углом между двумя пересекающимися прямыми называется меньший из образованных ими углов. Он никогда не бывает больше 90°. Угол между параллельными прямыми считается равным 0°.

Пример 4

При пересечении прямых AB и CD оказалось, что ∠DOB = 30°. Найти остальные углы и угол между прямыми.

1. ∠AOD смежный с ∠DOB: 180° − 30° = 150°.
2. ∠AOC вертикальный с ∠DOB, значит 30°.
3. ∠COB вертикальный с ∠AOD, значит 150°.
4. Угол между прямыми — меньший из них.
углы 30°, 150°, 30°, 150°; угол между прямыми 30°

Живой чертёж: две пересекающиеся прямые

Кнопка выбирает, что показать, ползунок меняет угол. Проверь на нём каждое свойство: сумму смежных, равенство вертикальных и что бывает при 90°.

Смежные, вертикальные, перпендикулярные

Доведи ползунок до 90° в режиме «перпендикулярность» — все четыре угла станут прямыми разом.

6. Перпендикулярные прямые

ОПРЕДЕЛЕНИЕ
Две прямые называются перпендикулярными, если они пересекаются под прямым углом.

При пересечении двух перпендикулярных прямых образуются четыре прямых угла. Достаточно, чтобы прямым оказался один из них: остальные три получаются прямыми сами — по свойствам смежных и вертикальных углов.

ОТРЕЗКИ И ЛУЧИ
Отрезки и лучи называются перпендикулярными, если они лежат на перпендикулярных прямых. Пишут m ⊥ n и говорят «взаимно перпендикулярны».

7. Перпендикуляр и расстояние до прямой

ОПРЕДЕЛЕНИЕ
Перпендикуляром к данной прямой называется отрезок, который лежит на прямой, перпендикулярной данной, и один из концов которого является точкой пересечения этих прямых. Этот конец называют основанием перпендикуляра.

Основание перпендикуляра называют ещё проекцией точки на прямую.

ДВА СЛОВА, КОТОРЫЕ ПУТАЮТ
Точка не лежит на прямой — перпендикуляр из неё опускают.
Точка лежит на прямой — перпендикуляр к ней восставляют.
Отрезок в обоих случаях один и тот же, разное только положение точки.
РАССТОЯНИЕ ОТ ТОЧКИ ДО ПРЯМОЙ
Длина перпендикуляра, проведённого из данной точки к данной прямой, принимается за расстояние от этой точки до прямой. Любой другой отрезок от точки до прямой длиннее.

8. Сколько перпендикуляров можно провести

ТЕОРЕМА
Через точку, лежащую на данной прямой, можно провести прямую, перпендикулярную этой прямой, и только одну.

Доказательство

Дано: прямая a, точка A на ней.
1. По аксиоме откладывания углов от луча AB в данную полуплоскость можно отложить угол 90°, и притом только один. Значит прямая AC, перпендикулярная a, существует.
2. Предположим, есть вторая такая прямая AD. Тогда ∠BAD тоже равен 90°.
3. Получилось, что от луча AB в одну полуплоскость отложены два разных угла по 90°. Это противоречит аксиоме.
второго перпендикуляра не существует
ТЕОРЕМА
Через точку, не лежащую на данной прямой, можно провести прямую, перпендикулярную этой прямой, и притом только одну.

Как её доказывают

1. Лист с чертежом мысленно перегибают по прямой a, совмещая полуплоскости. Точка A переходит в точку B по другую сторону от прямой.
2. Проводят прямую AB. Углы, которые она образует с прямой a, совпали при наложении, значит равны. А раз они ещё и смежные, каждый равен 90°.
3. Единственность доказывают так же: второй перпендикуляр после перегибания дал бы две разные прямые через две точки, а это противоречит аксиоме прямой.
Итог двух теорем: на плоскости через любую точку можно провести перпендикуляр к данной прямой, и притом только один.
ТЕОРЕМА (о двух прямых, перпендикулярных третьей)
На плоскости две прямые, перпендикулярные третьей, параллельны между собой.

Доказательство

Дано: a ⊥ c и b ⊥ c.
1. Предположим, что a и b пересекаются в точке M.
2. Тогда через точку M проходят две разные прямые, перпендикулярные прямой c. По предыдущей теореме это невозможно.
3. Значит a и b не пересекаются, то есть параллельны.
a ∥ b

9. Биссектрисы смежных и вертикальных углов

Пример 5 (ключевая задача)

Найти угол между биссектрисами OK и OM смежных углов ∠BOC и ∠AOC, если ∠BOC = 70°.

1. ∠AOC = 180° − 70° = 110°.
2. Биссектриса делит угол пополам: ∠COK = 35°, ∠COM = 55°.
3. ∠MOK = 35° + 55° = 90°.
∠MOK = 90°
СВОЙСТВО
Биссектрисы смежных углов перпендикулярны.

Доказательство в общем виде

1. ∠COM = ½ ∠AOC, ∠COK = ½ ∠BOC.
2. ∠MOK = ∠COM + ∠COK = ½ (∠AOC + ∠BOC).
3. По свойству смежных углов ∠AOC + ∠BOC = 180°.
4. Значит ∠MOK = ½ · 180° = 90°.
биссектрисы смежных углов перпендикулярны

Пример 6 (со звёздочкой)

Доказать, что биссектрисы вертикальных углов образуют развёрнутый угол.

1. Пусть OE и OK — биссектрисы вертикальных углов ∠AOC и ∠BOD.
2. Вертикальные углы равны, значит равны и их половины: ∠AOE = ∠BOK.
3. Лучи OA и OB дополнительные, поэтому ∠AOE + ∠EOC + ∠COB = 180°.
4. Заменим ∠AOE на равный ему ∠BOK: ∠BOK + ∠EOC + ∠COB = 180°.
5. Слева как раз и стоит ∠EOK, значит он развёрнутый.
∠EOK = 180°
Отсюда следует и обратное: если ∠AOB развёрнутый и ∠AOE = ∠BOK, то ∠AOE и ∠BOK вертикальные.

Живой чертёж: биссектрисы

Ползунок двигает луч, а угол между биссектрисами не меняется. Это и есть доказательство, только наглядное.

Что делают биссектрисы

Смежные углы всё время разные, а угол между их биссектрисами всегда 90°.

10. Узнаём пары углов по чертежу

Самая частая ошибка темы — решать по картинке, а не по определению. Смотрим только на стороны: общая они или дополнительные.

1 — смежные: общая сторона есть, две другие лежат на одной прямой.
2 — вертикальные: стороны одного продолжают стороны другого.

смежные · вертикальные · нет · нет · нет
Проверять надо не «на глаз», а по определению: общая сторона и дополнительные лучи.
Задание 47 · тетрадь, №3 (1-3)

Прямоугольный лист картона обрезали по прямой под углом 38° к его большей стороне. Какой угол образует линия разреза с большей стороной у второй, оставшейся части листа?
Показать решение
Линия разреза пересекает большую сторону, и по разные стороны от неё лежат два смежных угла.
180° − 38° = 142°.
142°
Если в ответе предлагают 148° или 152°, это ловушка: сумма с 38° должна давать ровно 180°.
Задание 60 · №43*
После того как один из смежных углов повернули вокруг вершины и увеличили на 40 %, другой угол уменьшился на 60 %. Найдите первоначальные величины этих углов.
Показать решение
1. Пусть углы равны a и b, причём a + b = 180°.
2. После поворота углы остались смежными: 1,4a + 0,4b = 180°.
3. Подставляем b = 180° − a: 1,4a + 72° − 0,4a = 180°, a = 108°.
первый = 108° · второй = 72°
Проверка: 1,4 · 108° = 151,2°, 0,4 · 72° = 28,8°, сумма 180°.
Задание 61 · №44*
Через одну точку на плоскости проходят четыре прямые, которые делят плоскость на 8 углов. Три из этих углов относятся как 1 : 2 : 3, а один из углов равен сумме трёх указанных. Найдите каждый угол.
Показать решение
1. Пусть три угла равны x, 2x, 3x. Четвёртый равен их сумме, то есть 6x.
2. Эти четыре угла занимают полуплоскость, а остальные четыре — вертикальные им и такие же.
3. 2(x + 2x + 3x + 6x) = 360°, то есть 24x = 360° и x = 15°.
15°, 30°, 45°, 90° — и ещё раз те же четыре угла
Проверка: 15 + 30 + 45 + 90 = 180, а вся сумма 360°.
Задание 62 · №38 · по чертежу
При пересечении двух прямых получились углы 1, 2, 3, 4 (подряд по кругу). Известно, что сумма углов 1, 2 и 3 равна 297°. Найдите сумму углов 2, 3 и 4.
Показать решение
1. ∠3 = ∠1 и ∠1 + ∠2 = 180°.
2. 2∠1 + ∠2 = 297°, подставляем ∠2 = 180° − ∠1: ∠1 = 117°, ∠2 = 63°.
3. ∠4 = ∠2 = 63°, поэтому ∠2 + ∠3 + ∠4 = 63° + 117° + 63°.
243°
Задание 63 · №39 · по чертежу
Два отрезка пересекаются, образуя четыре угла: α и φ снизу, β и γ сверху, причём α и γ вертикальные, β и φ вертикальные. Известно, что 2α + 3β + 4γ = 900°. Найдите φ.
Показать решение
1. Из вертикальности γ = α и φ = β.
2. α и β смежные: β = 180° − α.
3. 2α + 3(180° − α) + 4α = 900°, то есть 3α = 360° и α = 120°.
4. φ = β = 180° − 120°.
60°
Проверка: 2 · 120 + 3 · 60 + 4 · 120 = 900.

Смежные и вертикальные определяются расположением сторон, а не видом рисунка. При пересечении двух прямых достаточно знать один угол — остальные три находятся сразу. Если один из них прямой, прямыми оказываются все четыре, и прямые перпендикулярны. Через любую точку перпендикуляр к данной прямой ровно один, а длина этого перпендикуляра и есть расстояние от точки до прямой.
