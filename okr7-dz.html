Элементы

Окружность и круг

Окружность — линия: все точки на одинаковом расстоянии от центра.

Круг — часть плоскости, ограниченная окружностью, то есть вся закрашенная фигура.

Длина есть у окружности, площадь — у круга.

Радиус, хорда, диаметр

Радиус — от центра до точки окружности.

Хорда — между двумя точками окружности.

Диаметр — хорда через центр, он же два радиуса.

Дуга, сектор, сегмент

Дуга — часть окружности между двумя точками.

Сектор — часть круга между двумя радиусами и дугой.

Сегмент — часть круга между хордой и дугой.

Формулы

Диаметр

D = 2R

Диаметр вдвое больше радиуса, радиус — половина диаметра.

R = D : 2.

Длина окружности

C = 2πR = πD

Длина окружности всегда в π раз больше диаметра.

π ≈ 3,14 — отношение длины окружности к её диаметру.

Площадь круга

S = πR2

В формуле площади стоит радиус, а не диаметр.

Если дан диаметр, сначала найди радиус.

Две окружности

Касание внешнее

Круги касаются снаружи — расстояние между центрами равно сумме радиусов.

d = R + r

Точка касания лежит на отрезке между центрами.

Касание внутреннее

Одна окружность внутри другой и касается её — расстояние между центрами равно разности радиусов.

d = R − r

Отсюда R = d + r.

Кольцо

У концентрических окружностей общий центр. Часть плоскости между ними — кольцо.

S = πR2 − πr2

Ширина кольца равна R − r.

Живой чертёж

Нажимай названия — элемент загорается на чертеже, а снизу появляется определение. Это главный чертёж темы, к нему стоит возвращаться.

Нажимай кнопки — на чертеже загорается нужный элемент.

1. Окружность, круг и их элементы

ДВА РАЗНЫХ СЛОВА
Окружность — это линия: все её точки одинаково удалены от центра. Круг — часть плоскости, ограниченная окружностью, то есть линия вместе со всем, что внутри.

Поэтому говорят «длина окружности» и «площадь круга», а не наоборот.

ЭЛЕМЕНТЫ
Радиус — отрезок от центра до точки окружности. Все радиусы одной окружности равны.
Хорда — отрезок между двумя точками окружности.
Диаметр — хорда, проходящая через центр. Он состоит из двух радиусов, поэтому D = 2R.
Дуга — часть окружности между двумя точками. Две точки задают сразу две дуги.
Пощёлкай кнопки: где радиус, где хорда, а где диаметр.

Пример 1

Радиус окружности равен 1,9 см. Найди диаметр.

Диаметр вдвое больше радиуса.
D = 2R = 2 · 1,9 = 3,8 (см)
Обратная задача решается делением: если D = 11 см, то R = 11 : 2 = 5,5 см.

2. Длина окружности

ЧИСЛО " + PI + "
Отношение длины окружности к её диаметру одинаково у всех окружностей. Это число обозначают греческой буквой π и приближённо считают равным 3,14.
C = 2πR = πD

Букву π ввёл в 1706 году Уильям Джонс — с неё начинается греческое слово «измеряю вокруг». Международный день числа π отмечают 14 марта.

Пример 2

Радиус окружности 3 см. Найди её длину.

C = 2 · π · 3 = 6π (см)
Ответ чаще всего оставляют с π: так он точный. Если нужно число — умножаем на 3,14: 6 · 3,14 = 18,84 см.

3. Площадь круга

S = πR2
ГЛАВНАЯ ЛОВУШКА
В формуле площади стоит радиус. Если дан диаметр, сначала найди радиус, и только потом возводи в квадрат.

Пример 3

Радиус круга 3 см. Найди его площадь.

S = π · 32 = 9π (см2)
Сравни: при радиусе 3 см длина окружности 6π см, а площадь 9π см². Единицы разные: сантиметры и квадратные сантиметры.

4. Обратные задачи

КАК РАЗВОРАЧИВАТЬ ФОРМУЛУ
Дана длина — дели на 2π: R = C : (2π).
Дана площадь — дели на π и извлекай квадратный корень: R2 = S : π.

Пример 4

Площадь круга равна 0,16π м². Найди диаметр.

1. Делим на π: R2 = 0,16.
2. Значит R = 0,4 м.
D = 2R = 0,8 (м)
Когда в условии площадь записана «столько-то π», делить на π — это просто отбросить его.

Пример 5

Длина окружности 156π см. Найди радиус.

R = 156π : (2π) = 78 (см)
π сокращается — поэтому такие задачи решаются устно.

5. Две окружности

ЧЕТЫРЕ СЛУЧАЯ
Две окружности могут не иметь общих точек, пересекаться в двух точках или касаться в одной. Окружности с общим центром называют концентрическими, а часть плоскости между ними — кольцом.
внешнее касание: d = R + r
внутреннее касание: d = R − r

Пример 6

Два круга касаются. Площадь меньшего 25π см², диаметр большего 16 см. Найди расстояние между центрами.

1. Меньший: r2 = 25, значит r = 5 см.
2. Больший: R = 16 : 2 = 8 см.
d = 5 + 8 = 13 (см)
Если бы касание было внутренним, ответ был бы 8 − 5 = 3 см. Всегда смотри на рисунок.

Пример 7

Радиусы концентрических окружностей 5 см и 7 см. Найди площадь кольца.

S1 = 49π, S2 = 25π.
S = 49π − 25π = 24π (см2)
Площадь кольца — разность площадей, а ширина кольца — разность радиусов, то есть 2 см.

6. Задачи из жизни

ГДЕ ЭТО ВСТРЕЧАЕТСЯ
Бордюр вокруг клумбы — это длина окружности. Верёвка козлёнка — радиус. Один оборот колеса — тоже длина окружности. Орбита станции — окружность радиуса «радиус Земли плюс высота».

Пример 8

Колесо диаметром 64 см проехало 100 м. Сколько полных оборотов сделало колесо?

1. Один оборот — это длина окружности: C = π · 0,64 ≈ 2,011 м.
2. Делим путь на длину оборота: 100 : 2,011 ≈ 49,7.
49 полных оборотов
Полных — значит округляем вниз: 49,7 оборота — это 49 целых и ещё кусочек.

Окружность и круг. Окружность — линия, все точки которой одинаково удалены от центра; у неё есть длина. Круг — часть плоскости внутри окружности; у него есть площадь.

Элементы. Радиус — от центра до точки окружности. Хорда — между двумя точками окружности. Диаметр — хорда через центр, D = 2R. Дуга — часть окружности между двумя точками.

Части круга. Сектор — между двумя радиусами и дугой. Сегмент — между хордой и дугой. Полукруг — половина круга, ограниченная диаметром.

Длина окружности. C = 2πR = πD, где π ≈ 3,14 — отношение длины окружности к её диаметру.

Площадь круга. S = πR2. В формуле площади стоит радиус: если дан диаметр, сначала найди R.

Обратные задачи. Дана длина — R = C : (2π). Дана площадь — R2 = S : π, дальше извлекай корень.

Две окружности. Внешнее касание: d = R + r. Внутреннее касание: d = R − r. Общий центр — концентрические, между ними кольцо шириной R − r и площадью πR2 − πr2.

Прямая и окружность. Одна общая точка — касательная, две общие точки — секущая.

Из жизни. Бордюр вокруг клумбы и один оборот колеса — это длина окружности; верёвка из центра — радиус; орбита — окружность радиуса «радиус Земли плюс высота».
