1. Когда функция обратима

Посмотри на два графика. У первого любая горизонтальная прямая пересекает график не больше одного раза: каждое своё значение функция принимает при единственном значении аргумента. У второго значение 1 достигается сразу при трёх значениях аргумента.

Определение. Функция, которая каждое своё значение принимает только при одном значении аргумента, называется обратимой.

Графический признак: функция обратима тогда и только тогда, когда любая прямая, параллельная оси абсцисс, пересекает её график не более чем в одной точке.

2. Как проверить обратимость по формуле

Если функция задана формулой, проверка сводится к одному действию: решить уравнение y = f(x) относительно x.

  1. Решить уравнение y = f(x) относительно x.
  2. Посмотреть на результат: если каждому y отвечает единственное x, функция обратима.
Пример. Обратима ли функция y = 3x − 2?
3x = y + 2, значит x = (y + 2) : 3.
Каждому y отвечает ровно одно x, поэтому функция обратима.
Пример. Обратима ли функция y = x²?
x² = y даёт при y > 0 сразу два корня: x = √y и x = −√y.
Значит функция не обратима: например, значение 4 она принимает и при x = 2, и при x = −2.

3. Что такое обратная функция

Определение. Пусть функция y = f(x) обратима, D(f) — её область определения, E(f) — множество значений. Функция g, которая каждому значению y из E(f) ставит в соответствие то единственное x из D(f), при котором y = f(x), называется обратной к функции f.

Аргументом обратной функции служит переменная y, а её значением — переменная x. Но записывать функцию принято по-старому: аргумент обозначают через x, значение — через y. Поэтому в самом конце переменные переобозначают.

D(g) = E(f)   ·   E(g) = D(f)

Область определения и множество значений просто меняются ролями — это самая частая проверка себя: если у тебя получилось иначе, где-то ошибка.

4. Алгоритм: как записать обратную функцию

  1. Из равенства y = f(x) выразить x через y, то есть решить уравнение относительно x.
  2. В полученной формуле x = g(y) переобозначить: аргумент назвать x, значение назвать y.
  3. Записать функцию y = g(x).
  4. Указать область определения и множество значений: D(g) = E(f), E(g) = D(f).

Шаг 2 — не формальность. Пока не переобозначил переменные, у тебя записана та же самая зависимость, только с другой стороны. Обратной функцией она становится после переобозначения.

5. Монотонность — готовый пропуск в обратимость

Теорема 1. Если функция возрастает (убывает) на некотором промежутке, то она обратима на этом промежутке.

Почему. Пусть функция возрастает. Возьмём два разных значения аргумента, x₁ > x₂. Тогда f(x₁) > f(x₂), то есть значения тоже разные. Разным аргументам отвечают разные значения — значит одно и то же значение дважды получиться не может. Для убывающей функции рассуждение то же, только знак неравенства меняется.

Замечание: если функция возрастает, то и обратная к ней возрастает; если убывает — обратная тоже убывает.

Отсюда рабочий приём: функцию, необратимую целиком, можно сузить до промежутка монотонности — и на нём она уже обратима. Так поступают с параболой: на промежутке справа от вершины она возрастает.

6. Графики взаимно обратных функций

Теорема 2. Графики взаимно обратных функций симметричны относительно прямой y = x.

Почему. Пусть точка F(a; b) принадлежит графику функции f, то есть b = f(a). Тогда a = g(b), а значит точка G(b; a) принадлежит графику обратной функции. Четырёхугольник с вершинами F, G и точками D(a; a), E(b; b) прямой y = x — квадрат: его смежные стороны равны. Диагонали квадрата перпендикулярны и делятся точкой пересечения пополам, поэтому F и G симметричны относительно прямой y = x.

Проще говоря: у симметричных точек координаты меняются местами. Например графики y = 3x + 2 и y = x : 3 − 2 : 3 — зеркальные отражения друг друга в прямой y = x.

7. Алгоритм: построить график обратной функции

  1. Для данной функции отметить на оси абсцисс область определения, на оси ординат — множество значений.
  2. Для обратной функции отметить на оси абсцисс D(g) = E(f), а на оси ординат E(g) = D(f).
  3. Построить прямую y = x.
  4. Построить график, симметричный данному относительно прямой y = x.

Разобранные примеры

Пример 1. Линейная функция

Найдите функцию, обратную к y = 3x − 2.
Показать решение
1. Функция линейная и возрастает (коэффициент 3 положительный), значит по теореме 1 она обратима.
2. Выражаем x: 3x − 2 = y → 3x = y + 2 → x = (y + 2) : 3.
3. Переобозначаем переменные:
y = (x + 2) : 3
4. D(f) = R и E(f) = R, поэтому D(g) = R, E(g) = R.
Ответ: g(x) = (x + 2) : 3.
Проверка: g(3 · 5 − 2) = g(13) = 15 : 3 = 5 — вернулись к исходному аргументу, значит формула верна.

Пример 2. Дробно-рациональная функция

Обратима ли функция y = 2 : (x − 3)? Если да, найдите обратную и укажите D(g) и E(g).
Показать решение
1. Область определения: знаменатель не равен нулю, поэтому D(f) = (−∞; 3) ∪ (3; +∞).
2. Выражаем x: 2 = y(x − 3) → x − 3 = 2 : y → x = 2 : y + 3.
3. Каждому y ≠ 0 отвечает ровно одно x, значит функция обратима.
4. Переобозначаем:
y = 2 : x + 3
5. Дробь 2 : (x − 3) нулём не бывает, поэтому E(f) = (−∞; 0) ∪ (0; +∞). Значит D(g) = (−∞; 0) ∪ (0; +∞), E(g) = (−∞; 3) ∪ (3; +∞).
Ответ: g(x) = 2 : x + 3.

Пример 3. Парабола на промежутке

Обратима ли функция y = x² − 4x + 5 при x ∈ (2; +∞)? Если да, найдите обратную.
Показать решение
1. Абсцисса вершины параболы: x₀ = 4 : 2 = 2. Справа от вершины парабола с ветвями вверх возрастает, значит на промежутке (2; +∞) функция обратима.
2. Найдём E(f): в вершине y = 2² − 4 · 2 + 5 = 1, дальше функция растёт, и точка x = 2 в промежуток не входит. Значит E(f) = (1; +∞).
3. Решаем относительно x: x² − 4x + 5 − y = 0.
D = 16 − 4(5 − y) = 4y − 4,   √D = 2√(y − 1)
4. x = (4 ± 2√(y − 1)) : 2 = 2 ± √(y − 1). Так как x > 2, берём знак плюс: x = 2 + √(y − 1).
5. Переобозначаем:
y = 2 + √(x − 1)
6. D(g) = E(f) = (1; +∞), E(g) = D(f) = (2; +∞).
Ответ: g(x) = 2 + √(x − 1).
Знак перед корнем выбирается по области определения. Если бы было задано x < 2, ответ был бы 2 − √(x − 1).

Пример 4. Корень

Найдите функцию, обратную к y = √(x − 4), и укажите D(g), E(g).
Показать решение
1. D(f) = [4; +∞), корень неотрицателен, поэтому E(f) = [0; +∞). Функция возрастает — значит обратима.
2. Возводим в квадрат: y² = x − 4 → x = y² + 4.
3. Переобозначаем и не забываем ограничение, унаследованное от E(f):
y = x² + 4 при x ≥ 0
4. D(g) = E(f) = [0; +∞), E(g) = D(f) = [4; +∞).
Ответ: g(x) = x² + 4 при x ≥ 0.
Условие x ≥ 0 обязательно: без него это была бы парабола целиком, а она не обратна нашей функции.

Пример 5. Чтение по графику

На рисунке изображён график обратимой функции y = f(x). Найдите g(2) и g(−0,5), где g — обратная функция.
Показать решение
1. Найти g(2) — значит ответить на вопрос: при каком x значение функции равно 2. Ищем на графике точку с ординатой 2 и смотрим её абсциссу: x = 6.
2. Так же g(−0,5): ордината −0,5 достигается при x = 3.
Ответ: g(2) = 6, g(−0,5) = 3.
Работа с обратной функцией по графику — это всегда «читать наоборот»: не от x к y, а от y к x.
