1. Что такое рациональное выражение

ОПРЕДЕЛЕНИЕ
Выражение, собранное из чисел и переменных только с помощью сложения, вычитания, умножения, деления и возведения в натуральную степень, называют рациональным.

Запрещено ровно одно: извлекать корень из выражения с переменной. Сам по себе корень из числа — это просто число, он ничего не портит.

Пример 1

выражениерациональное?почему
6,7z + 23xyдатолько умножение и сложение
2√xyнеткорень из выражения с переменными
x + yx − 6даделение разрешено
√2 · xдапод корнем число, а не переменная
Проверяй по одному действию: увидел корень — смотри, что под ним. Буква под корнем — выражение уже не рациональное.
Задание 1Две задачи. Считай выражения по одному и ставь галочку.

2. Целое или дробное

ЕДИНСТВЕННЫЙ ВОПРОС
Есть ли в выражении деление на выражение с переменной? Нет — выражение целое рациональное. Да — дробное рациональное.

Деление на число ничего не меняет: 5a3 − 1 остаётся целым, сколько бы дробных чёрточек там ни стояло. Важна только буква в знаменателе.

Пример 2

выражениечто в знаменателевывод

5a3 − 1число 3целое
6x − 9x − 9, есть буквадробное
mnn, есть буквадробное
5 + x2 − 12x + 32x + 3дробное
Ловушка: 1a − 2,5 выглядит почти как число, но деление на a есть — значит дробное.
Задание 2Две задачи на пересчёт. Сначала отметь в каждом выражении знаменатель, потом считай.

3. Рациональная дробь

Напомню: многочлен — это сумма одночленов. Многочлены: x2 − 5x + 6,  7,  m,  2x + 3. Не многочлены: √x,  1x.

ОПРЕДЕЛЕНИЕ
Дробь, у которой и числитель, и знаменатель — многочлены, называется рациональной дробью.
ТО, ЧТО ОБЫЧНО ПУТАЮТ
«Рациональная дробь» и «дробное выражение» — разные вещи. 14c15 — рациональная дробь (оба этажа многочлены), но деления на переменную в ней нет, значит она ещё и целое выражение. Поэтому на схеме круг дробей лежит на границе.

Пример 3

Все пять — рациональные дроби, потому что на обоих этажах многочлены:

14c15  2xx4 + 2  6p − 5  m6m2 + 3  89c

А эти — нет:

5√x + 1  1x2 + x  (x − y)2 + 2x
У первой знаменатель не многочлен. Вторая и третья вообще не записаны одной дробью — это суммы.
Задание 3Две задачи: посчитать дроби и определить, чем является выражение.

4. Значение дроби

ПОРЯДОК
Подставить числа вместо букв. Посчитать отдельно числитель, отдельно знаменатель, и только потом поделить.

Главная потеря — знаки. Отрицательное число всегда подставляй в скобках: при n = −5 выражение 2n даёт 2 · (−5) = −10, а −n даёт +5.

Пример 4

а) Найти значение x + 3x − 3 при x = 0.

0 + 30 − 3 = 3−3 = −1

б) Найти значение a + 8a − 1 при a = 0,5.

Знаменатель: 0,5 − 1 = −0,5. Дробь: 8 : (−0,5) = −16.
0,5 + (−16) = −15,5

в) Найти значение 2m − n3m + 2n при m = 4, n = −5.

Числитель: 2 · 4 − (−5) = 8 + 5 = 13. Знаменатель: 3 · 4 + 2 · (−5) = 12 − 10 = 2.
132 = 6,5
Если знаменатель вышел нулём — значения у выражения нет. Это не «ноль» и не «бесконечность», а именно «не существует».
Задание 4Три задачи. Считай числитель и знаменатель в две отдельные строки — так ошибку видно сразу.

5. Область определения

ОПРЕДЕЛЕНИЕ
Область определения рациональной дроби — все значения переменной, кроме тех, при которых знаменатель обращается в нуль.

Пример 5

а) 5xx − 4

x − 4 = 0 → x = 4. Четвёрку выбрасываем.
x ∈ (−∞; 4) ∪ (4; +∞)

б) 6y − 1y(y + 8)

Произведение равно нулю, когда нулю равен хотя бы один множитель: y = 0 или y + 8 = 0, то есть y = −8.
y ∈ (−∞; −8) ∪ (−8; 0) ∪ (0; +∞)

в) 7a − 4a2 + 9

a2 ≥ 0 всегда, значит a2 + 9 ≥ 9 и нулём не бывает. Выбрасывать нечего.
a ∈ R
Два запоминания. Первое: выбрасывают корни знаменателя, а не сам знаменатель. Второе: сумма квадрата и положительного числа нулём не бывает никогда.
Задание 5Две задачи. Пиши уравнение «знаменатель = 0» отдельной строкой.

Проверь себя

Здесь ответ вписывается числом. Десятичную дробь пиши через запятую.
Тренажёр 2. Где знаменатель обнуляется

6. Когда дробей несколько

ПРАВИЛО
Каждая дробь добавляет свои запреты. Приравниваем к нулю каждый знаменатель по очереди и выбрасываем все найденные числа сразу. Целая часть выражения запретов не даёт.

Пример 6

а) x3 − 4x2 + 2 — выражение целое, деления на переменную нет.

x ∈ R

б) 5x − 1 + x + 6x + 3

Первый знаменатель: x − 1 = 0 → x = 1. Второй: x + 3 = 0 → x = −3.
x ∈ (−∞; −3) ∪ (−3; 1) ∪ (1; +∞)

в) x − 6x + 5x − 2

x = 0 и x − 2 = 0 → x = 2.
x ∈ (−∞; 0) ∪ (0; 2) ∪ (2; +∞)
Числа выписывают по возрастанию — так ни одно не потеряется и промежутки встанут сами собой.
Задание 6Две задачи. Разложи знаменатели на множители — иначе корень легко проглядеть.

Проверь себя

Последний тренажёр — целиком про область определения.
Тренажёр 3. Область определения
Восемь выражений. Здесь уже несколько дробей и разложение на множители.

7. Дробь внутри дроби

ДВА УСЛОВИЯ
Сначала не должен обнулиться знаменатель маленькой дроби. Потом — знаменатель большой. Оба запрета идут в ответ.

Пример 7

Найти область определения выражения x1 − 5x

1. Маленькая дробь 5x: знаменатель x, значит x ≠ 0.
2. Большой знаменатель: 1 − 5x ≠ 0. Решаем как уравнение: 1 = 5x, отсюда x = 5. Значит x ≠ 5.
x ∈ (−∞; 0) ∪ (0; 5) ∪ (5; +∞)
Забыть первое условие — самая частая потеря: нуль в большой знаменатель не подставляется вообще, там уже нет смысла.
Задание 7Одна задача со звёздочкой. Выпиши оба условия, прежде чем считать.

Шпаргалка

Печатается на один лист A4: Ctrl+P (⌘+P) → печать.

Рациональное выражение — только + − · : и натуральная степень. Корень из выражения с переменной делает выражение нерациональным; корень из числа (√2) не мешает.

Целое или дробное. Один вопрос: делим ли на выражение с переменной? Нет — целое (5a/3 − 1, x + (x³ − 1)/12). Да — дробное (6/(x − 9), 1/a − 2,5). Деление на число ничего не меняет.

Рациональная дробь — записана одной дробью, и числитель, и знаменатель многочлены. 14c/15 — дробь и при этом целое выражение. Сумма 1/x² + x дробью не является.

Значение дроби. Числитель и знаменатель считают отдельно, отрицательные числа подставляют в скобках: (−1)² = 1, а −1² = −1. Знаменатель вышел нулём — значения нет.

Область определения — все числа, кроме корней знаменателя. Три шага: знаменатель = 0 → решить → выбросить. x² = 16 даёт два числа, 4 и −4. Из x + 6 = 0 выходит −6, а не 6.

Несколько дробей — запреты складываются: приравнивают к нулю каждый знаменатель. Квадратный знаменатель раскладывают на множители: x² + 3x = x(x + 3) → 0 и −3; x² − 6x + 9 = (x − 3)² → только 3.

Знаменатель без нулей. a² + 9, 2m² + 5, x² + 7 — всегда положительны, выбрасывать нечего, область определения — все числа.

Дробь внутри дроби — два условия: знаменатель маленькой дроби ≠ 0 и знаменатель большой ≠ 0. В x/(x − 16/x) выброшены 0, 4 и −4.
