Сложение и вычитание десятичных дробей

Математика · 6 класс · §4 · теория порциями, живой столбик, 4 тренажёра, 18 задач
Как работать. Страница идёт по кругу: короткая порция теории — разобранный пример — тренажёр или задачи ровно на эту порцию. Не перепрыгивай вперёд.
Главная мысль всей темы: запятая под запятой, а недостающие знаки после запятой дополняем нулями справа.
У каждой задачи есть кнопка «Столбик»: она открывает живой столбик прямо в задаче. Страница сама допишет нули, а ты вписываешь ответ по разрядам и сразу видишь, где ошибся.
Все четыре тренажёра нужно пройти до конца — без этого работа не отправится. Ошибки в тренажёре не страшны: важно дойти до итога и прочитать разбор.

Что спрашивают чаще всего

Законы сложения работают

a + b = b + a
(a + b) + c = a + (b + c)

Слагаемые можно менять местами и группировать — этим пользуются, чтобы получались круглые числа.

0,23 + (2,38 + 14,77) = (0,23 + 14,77) + 2,38 = 15 + 2,38 = 17,38.

Скобки вперёд

4,2 − (0,98 + 1,75)

Сначала считаем в скобках, потом всё остальное. В скобках 2,73, дальше 4,2 − 2,73 = 1,47.

Если скобок нет, идём слева направо.

Уравнение

45 − x = 38,783

Неизвестное вычитаемое: x = 45 − 38,783 = 6,217.

Неизвестное слагаемое ищут вычитанием, уменьшаемое — сложением.

Рабочий столбик

Впиши любые два числа, выбери знак — и посчитай по разрядам. Этот столбик никуда не отправляется, считай в нём сколько угодно.

Серые нули страница дописывает сама — именно так и делают в тетради.

ГЛАВНОЕ ПРАВИЛО
Запятая пишется строго под запятой. Тогда одноимённые разряды встают друг под друга, и дальше складываем как обычные числа. В ответе запятая — в том же столбце.

Пример 1

Найди значение выражения 5,2 + 1,46.

1. Пишем запятую под запятой.
2. У 5,2 не хватает сотых — дописываем нуль: 5,20.
3. Складываем справа налево: 0 + 6 = 6, 2 + 4 = 6, 5 + 1 = 6.
5,2 + 1,46 = 6,66
Проверка на глаз: 5,2 чуть больше пяти, 1,46 чуть меньше полутора — ответ должен быть около 6,7. Сошлось.

Попробуй сам: впиши числа и заполни ответ по разрядам.

Пример 2

Найди значение выражения 2,8 − 0,009.

1. У 2,8 одна цифра после запятой, у 0,009 — три. Дописываем: 2,800.

3. Разрядные слагаемые

Любую десятичную дробь можно разложить по разрядам — это помогает не путать, где десятые, а где сотые.

57,1083 = 50 + 7 + 0,1 + 0,008 + 0,0003
КАК ЧИТАТЬ
Каждая цифра отвечает за свой разряд: десятки, единицы, десятые, сотые, тысячные, десятитысячные. Нулевые разряды в сумму не пишут, но место за собой держат.

Пример 3

Разложи по разрядам число 0,567.

5 — это десятые, 6 — сотые, 7 — тысячные.
0,567 = 0,5 + 0,06 + 0,007
Обрати внимание: у 57,1083 нет сотых, поэтому в сумме между 0,1 и 0,008 ничего не стоит. Цифра 0 разряд не отменяет — она его занимает.

4. Законы сложения

ПРИЁМ
Слагаемые можно переставлять и группировать. Ищи пары, которые дают круглое число — считать станет вдвое быстрее.
a + b = b + a
(a + b) + c = a + (b + c)

Пример 4

Найди значение выражения 0,23 + (2,38 + 14,77).

1. Замечаем пару: 0,23 и 14,77 дают ровно 15.
2. Переставляем: (0,23 + 14,77) + 2,38.
15 + 2,38 = 17,38
Если считать подряд, ответ тот же, но столбиков будет два и оба «некрасивые». Ищи круглые пары — это и есть смысл законов сложения.
Проверь сам: сложи 0,23 и 14,77 — должно выйти ровное 15.

5. Выражения со скобками

ПОРЯДОК ДЕЙСТВИЙ
Сначала считаем в скобках, потом всё остальное. Если скобок нет — слева направо. Каждое действие записывают отдельным столбиком.

Пример 5

Найди значение выражения 4,2 − (0,98 + 1,75).

1. В скобках: 0,98 + 1,75 = 2,73.
2. Теперь вычитаем: 4,2 − 2,73. Дописываем нуль: 4,20.
4,20 − 2,73 = 1,47
Не пытайся вычитать «по частям»: 4,2 − 0,98 − 1,75 тоже даёт 1,47, но только если вычитать оба числа. Минус перед скобкой относится ко всей сумме.

Посчитай оба действия здесь: сначала 0,98 + 1,75, потом 4,2 − то, что вышло.

После первого действия нажми «Другие числа» и посчитай второе.

6. Уравнения

ЧТО ИЩЕМ
Неизвестное слагаемое — из суммы вычитаем известное слагаемое.
Неизвестное уменьшаемое — к разности прибавляем вычитаемое.
Неизвестное вычитаемое — из уменьшаемого вычитаем разность.

Пример 6

Реши уравнение 45 − x = 38,783.

1. Здесь x — вычитаемое, значит x = 45 − 38,783.
2. Дописываем нули: 45,000 − 38,783.
x = 6,217
Проверка обязательна: 45 − 6,217 = 38,783. Сошлось.

Пример 7

Реши уравнение (x + 93,4) − 17,4 = 112,72.

1. Сначала считаем скобку как одно число: x + 93,4 = 112,72 + 17,4 = 130,12.
2. Теперь x = 130,12 − 93,4.
x = 36,72
Двигайся снаружи внутрь: сперва убираем то действие, которое выполняется последним.
Столбик под рукой: посчитай 45 − 38,783 и проверь себя.

ВОССТАНОВИТЬ ЦИФРУ
Если в примере потеряна цифра, её находят обратным действием: из суммы вычитают известное слагаемое.

Пример 8

Восстанови цифру: 4,2? + 1,38 = 5,65.

1. Находим первое слагаемое: 5,65 − 1,38 = 4,27.

Проверяем: 4,27 + 1,38 = 5,65. Сошлось.
РАССТАВИТЬ ЗАПЯТЫЕ
Запятые ставят так, чтобы равенство стало верным. Помогает прикидка: примерно каким должен быть ответ.

Пример 9

Расставь запятые: 57 + 23 = 8.

Ответ однозначный, значит слагаемые — единицы с десятыми.
5,7 + 2,3 = 8
Приём один: смотри на ответ. Он подсказывает, какого размера должны быть слагаемые.
ЦЕПОЧКА ДЕЙСТВИЙ
Когда число несколько раз увеличивали и уменьшали, все прибавки и убавки можно собрать вместе, а потом пойти в обратную сторону.
Здесь без столбика не обойтись: считай по шагам.
Задание 7Четыре задачи повышенной сложности.

Шпаргалка

Печатается на один лист A4: Ctrl+P (⌘+P) → печать.

Правило столбика. 1) Запятая под запятой. 2) Уравнять число знаков после запятой, дописывая справа нули. 3) Считать как натуральные числа. 4) В ответе поставить запятую под запятыми.

Приписать нули. 1,4 = 1,400; 14 = 14,00; 30 = 30,000. Величина не меняется, а разряды встают на место.

Законы сложения. a + b = b + a и (a + b) + c = a + (b + c). Ищи пары с круглой суммой: 0,23 + 14,77 = 15; 4,5 + 2,5 = 7.

Скобки. Сначала скобки, потом остальное: 4,2 − (0,98 + 1,75) = 4,2 − 2,73 = 1,47.

Разрядные слагаемые. 57,1083 = 50 + 7 + 0,1 + 0,008 + 0,0003. Нулевые разряды не пишут, но место за собой держат.

Уравнения. Слагаемое = сумма − второе слагаемое. Уменьшаемое = разность + вычитаемое. Вычитаемое = уменьшаемое − разность.

Скорость по реке. По течению складываем, против течения вычитаем: 37,5 + 2,8 = 40,3 и 37,5 − 2,8 = 34,7.

Расставить запятые. Смотри на ответ — он задаёт размер слагаемых: 57 + 23 = 8 превращается в 5,7 + 2,3 = 8.

Проверка. Сложение проверяют вычитанием, вычитание — сложением. И всегда полезна прикидка: примерно каким должен быть ответ.
