Графики y = f(|x|) и y = |f(x)|

Алгебра · 10 класс · §3 · теория порциями, 4 тренажёра, 18 задач
Как работать. Страница идёт по кругу: короткая порция теории — разобранный пример — задачи ровно на эту порцию. Не перепрыгивай вперёд.
Вся тема держится на одном различии: модуль у аргумента отражает график в вертикальной оси, модуль у всей функции — в горизонтальной. Если это место усвоено, остальное выводится.
Каждый график строй в тетради: оси, вершина, нули, углы, пунктиром та часть, которую отражаешь. В нескольких задачах спрашивают именно координаты ключевых точек — выписывай их сразу, как построил. В поле вводи только ответ. У каждой задачи три подсказки; решение открывается после верного ответа или после второй попытки.

1. Модуль у аргумента: y = f(|x|)

Запишем модуль по определению и подставим его в функцию:

|x| = x при x ≥ 0  и  |x| = −x при x < 0
y = f(|x|) = f(x) при x ≥ 0  и  y = f(−x) при x < 0

Значит справа от оси ординат ничего не меняется: там |x| = x, и график совпадает с исходным. А слева значение функции при аргументе −5 равно значению исходной функции при аргументе 5 — то есть левая половина становится зеркальным отражением правой.

Главное. Функция y = f(|x|) всегда чётная: её график симметричен относительно оси ординат. Поэтому левую часть исходного графика в построении вообще не используют — её заменяет отражение правой.
  1. Построить график функции y = f(x).
  2. Удалить часть графика, расположенную левее оси ординат.
  3. Отразить симметрично относительно оси ординат часть графика правее оси ординат.
Задание 1Четыре задачи на внутренний модуль. Две последние — построить график и назвать координаты ключевых точек.

2. Модуль у всей функции: y = |f(x)|

y = |f(x)| = f(x) при f(x) ≥ 0  и  y = −f(x) при f(x) < 0

Здесь смотрим не на знак аргумента, а на знак самой функции. Всё, что было выше оси абсцисс, остаётся на месте. Всё, что было ниже, отражается наверх.

Главное. График функции y = |f(x)| никогда не опускается ниже оси абсцисс. Точки пересечения с осью абсцисс остаются на своих местах — и превращаются в углы графика.
  1. Построить график функции y = f(x).
  2. Отразить симметрично относительно оси абсцисс часть графика, расположенную ниже оси абсцисс.
  3. Удалить часть графика, расположенную ниже оси абсцисс.
Задание 2Четыре задачи на внешний модуль. Нули остаются на месте и становятся углами — на этом держатся две последние.

3. Два модуля сразу: y = |f(|x|)|

Порядок действий диктуют сами скобки: сначала работает внутренний модуль, потом внешний.

  1. Построить y = f(x).
  2. Сделать внутренний модуль: получить y = f(|x|) — отражением правой части влево.
  3. Сделать внешний модуль: то, что оказалось ниже оси абсцисс, отразить наверх.

Порядок можно поменять местами и получить тот же результат, но так путаницы меньше: идём изнутри наружу, как при вычислении по формуле.

5. Сколько получится нулей

Это самый частый вопрос по теме, и он решается без чертежа.

Для y = f(|x|): решаем f(t) = 0 и берём только неотрицательные корни t. Каждый положительный корень даёт два нуля (t и −t), а корень t = 0 — один.

Для y = |f(x)|: количество нулей не меняется вообще, потому что |f(x)| = 0 равносильно f(x) = 0.

|x|² = x², поэтому x² − 4|x| + 3 — это f(|x|) для f(x) = x² − 4x + 3

Приём с |x|² = x² — рабочая лошадка темы: он позволяет увидеть внутренний модуль там, где его на первый взгляд нет.

6. Наибольшее и наименьшее значение

КАК ИСКАТЬ
Модуль у аргумента: делаем замену t = |x|, но ищем вершину только среди неотрицательных t. Модуль у всей функции: наименьшее значение равно нулю, если у исходной функции есть хотя бы один нуль.

Пример 6. Наименьшее значение y = x² − 4|x| + 3

1. Замена t = |x| ≥ 0 даёт y = t² − 4t + 3. Вершина при t = 4 : 2 = 2, и двойка неотрицательна — значит она годится.
2. Значение в вершине: 4 − 8 + 3 = −1.
Наименьшее значение равно −1, и достигается оно дважды: при x = 2 и при x = −2.
Почему дважды: после отражения правая яма скопировалась влево. У любой функции вида f(|x|) все значения, кроме значения в нуле, достигаются парами.

Пример 7. Наибольшее значение y = −3|x| + 4

Модуль неотрицателен, значит −3|x| ≤ 0, и всё выражение не больше 4. Равенство достигается при x = 0.
Наибольшее значение равно 4.
Коэффициент перед модулем отрицательный — получается «шалаш». Если бы он был положительным, вышла бы «галка» и речь шла бы о наименьшем значении.
Задание 6Две задачи на наибольшее и наименьшее значение.

7. Дробь с модулем

ПОРЯДОК
Модуль в дроби раскрывают по промежуткам: отдельно при x ≥ 0 и отдельно при x < 0. Сокращать можно только после того, как выписана область определения — выколотые точки от сокращения никуда не деваются.

Пример 8. y = (|x| − 3) : (x² − 9)

1. Область определения: x² − 9 ≠ 0, значит x ≠ 3 и x ≠ −3. Обе точки будут выколоты, что бы дальше ни сократилось.
2. При x ≥ 0 модуль раскрывается как x:
(x − 3) : ((x − 3)(x + 3)) = 1 : (x + 3)
3. При x < 0 модуль раскрывается как −x:
(−x − 3) : ((x − 3)(x + 3)) = −(x + 3) : ((x − 3)(x + 3)) = 1 : (3 − x)
Результат: две ветви гиперболы, склеенные в точке (0; ⅓), и две выколотые точки на высоте 1/6 — при x = 3 и при x = −3.
Проверка: обе ветви в точке x = 0 дают 1 : 3, поэтому разрыва в нуле нет. А вот в точках ±3 разрыв есть, хотя после сокращения формула выглядит совершенно безобидно.
Задание 7Одна задача со звёздочкой — из самостоятельной повышенного уровня.

Шпаргалка

y = f(|x|) — модуль у аргумента. Стереть всё левее оси ординат и отразить туда правую часть. Результат всегда чётный: график симметричен относительно оси ординат.

y = |f(x)| — модуль у всей функции. Отразить вверх всё, что было ниже оси абсцисс. Результат нигде не ниже оси абсцисс, нули остаются на месте и становятся углами.

y = |f(|x|)| — сначала внутренний модуль, потом внешний.

Ключ ко всем задачам на корни: |x|² = x², поэтому x² − 4|x| + 3 — это f(|x|) для f(x) = x² − 4x + 3. Замена t = |x| ≥ 0, решаем по t, отбрасываем отрицательные корни. Положительный t даёт два икса, t = 0 — один.

Нули. У |f(x)| их столько же, сколько у f. У f(|x|) — удвоенное число неотрицательных корней, минус один, если среди них есть нуль.

Наибольшее и наименьшее. У |f(x)| наименьшее значение равно 0, если у f есть нули. У f(|x|) ищем вершину только среди t ≥ 0.

Уравнение |f(x)| = a при a > 0 распадается на два: f(x) = a и f(x) = −a. Проверяй каждое на дискриминант: x² = 0 даёт один корень, а не два.

Проверка за секунду. Был внутренний модуль, а график несимметричен относительно оси ординат — ошибка. Был внешний, а часть графика ушла ниже оси абсцисс — тоже ошибка.
