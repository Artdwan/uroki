Угол — между этими двумя сторонами. В формуле треугольника есть ½, в формуле параллелограмма — нет.

Шаг 2 Среднее пропорциональное в прямоугольном треугольнике

коротко о правиле
СРЕДНЕЕ ПРОПОРЦИОНАЛЬНОЕ
Если для положительных чисел a, b и c выполняется пропорция
ab = bc
то число b называется средним пропорциональным чисел a и c.
Из пропорции b² = ac, откуда b = √ac.
Поэтому b ещё называют средним геометрическим чисел a и c.
Пример. 4 = √2 · 8 — среднее пропорциональное чисел 2 и 8.
ПРОЕКЦИИ КАТЕТОВ
△ABC, ∠C = 90°, CK — высота.
AK — проекция катета AC на гипотенузу.
BK — проекция катета BC на гипотенузу.
Проекция «прилежит» к своему катету: у AC и AK общая точка A.
ТЕОРЕМА, пункт а)
Высота прямоугольного треугольника, проведённая к гипотенузе, есть среднее пропорциональное между проекциями катетов на гипотенузу:
CK² = AK · KBCK = √AK · KB
Доказательство — нажми, чтобы открыть
∠BCK = ∠A — эти углы дополняют ∠B до 90°.
Из △ACK: tg A = CKAK.
Из △BCK: tg∠BCK = BKCK.
Углы равны → тангенсы равны: BKCK = CKAK.
Отсюда CK² = AK · BK, CK = √AK · BK.
КАК ЗАПИСЫВАТЬ
Ссылку на теорему пишем словами:
«Так как высота CH есть среднее геометрическое между проекциями катетов на гипотенузу, то …».
Сначала квадрат, потом корень: CH² = AH · HB, CH = √AH · HB.
ТЕОРЕМА, пункт б)
Катет есть среднее пропорциональное между гипотенузой и проекцией этого катета на гипотенузу:
AC² = AB · AKBC² = AB · KB
Доказательство — нажми, чтобы открыть
Из △ACK: cos A = AKAC.
Из △ABC: cos A = ACAB.
Значит, AKAC = ACAB, AC² = AB · AK.
Аналогично BC² = AB · KB. Теорема доказана.
ФОРМУЛЫ В БУКВАХ
Катеты a и b, гипотенуза c, высота hc, проекции катетов ac и bc.
hc² = ac · bc
a² = c · acb² = c · bc
НЕ ПУТАЙ ПРОЕКЦИИ
В формулу катета входит его собственная проекция —
отрезок гипотенузы от вершины этого катета до основания высоты.

Запись в тетради
Решение. Пусть CH — высота прямоугольного треугольника ABC (∠C = 90°),

Так как высота CH есть среднее геометрическое между проекциями катетов на гипотенузу, то
CH = √AH · HB = √2 · 8 = 4 (см),
SABC = 12 AB · CH = 12 · 10 · 4 = 20 (см²).
Ответ: 20 см².
