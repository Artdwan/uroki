Минус — источник большинства ошибок

Минус перед скобкой

a − (b + c) = a − b − c

Меняется знак каждого слагаемого в скобке, а не только первого.

2x + 4 − (2a + 5 − 3x) = 5x − 2a − 1.

Вынесение минуса

−15x + 20a − 45 = −5(3x − 4a + 9)

Все знаки в скобке меняются на противоположные.

Сомневаешься — раскрой скобки обратно и сверь.

Минус перед дробью

2x + 54 − 3x − 42 = 2x + 5 − 2(3x − 4)4

Числитель второй дроби берём в скобки — иначе знак потеряется.

Итог здесь: −4x + 134.

Термины

Уравнение и корень

Корень — значение переменной, при котором равенство становится верным.

Проверка одна: подставить и посчитать обе части.

Решить уравнение — найти все корни, а не один.

Равносильные уравнения

Это уравнения с одними и теми же корнями.

5x − 25 = 0 и 2x − 7 = 3 равносильны: у обоих x = 5.

Произведение равно нулю

(x + 3)(x − 5)(x + 1) = 0

Произведение равно нулю, если хотя бы один множитель равен нулю.

Приравниваем к нулю каждую скобку по очереди.

Линейное уравнение

Линейное уравнение

ax + b = 0,   a ≠ 0
x = −ba

Неизвестное стоит в первой степени.

Алгоритм

1. Раскрыть все скобки.

2. С переменной — налево, без переменной — направо, меняя знаки.

3. Привести подобные: получится ax = b.

4. Разделить: x = b : a.

Три исхода

a ≠ 0 — ровно один корень.

0 = 0 — корней бесконечно много.

0 = 13 — корней нет.

Ноль в ответе (x = 0) — это обычный корень, а не «нет корней».

Опасные преобразования

Что делать можно

Заменять выражение тождественно равным.

Переносить слагаемые через знак равно со сменой знака.

Умножать и делить обе части на число, не равное нулю.

Посторонний корень

x − 1 = 0  →  (x − 1)(x − 3) = 0

Умножили на выражение с переменной — появился лишний корень x = 3.

Поэтому умножать на выражение с x нельзя.

Потеря корня

(x − 2)(x − 4) = (x − 4)

Сократили на (x − 4) — потеряли корень x = 4.

Сокращать в уравнении можно только числа.

1. Минус — главный источник ошибок

Прежде чем браться за уравнения, разберёмся с вычитанием. Именно на нём теряется больше всего баллов.

ПРАВИЛО 1
Знак «минус» перед скобкой меняет знаки всех слагаемых внутри скобки на противоположные, а не только первого.
2x + 4 − (2a + 5 − 3x) = 2x + 4 − 2a − 5 + 3x = 5x − 2a − 1
ПРАВИЛО 2
Вынося за скобки отрицательный множитель, меняем знаки всех слагаемых, которые остаются в скобках.
−15x + 20a − 45 = −5(3x − 4a + 9)
ТИПИЧНАЯ ОШИБКА
−15x + 20a − 45 = −(15x + 20a − 45) — так писать нельзя. Нельзя менять знак только перед первым слагаемым.

Не уверен — раскрой скобки обратно и сверь:

−5(3x − 4a + 9) = −15x + 20a − 45
ПРАВИЛО 3
Если перед дробью стоит минус, возьми числитель этой дроби в скобки — тогда при приведении к общему знаменателю знак не потеряется.
2x + 54 − 3x − 42 = 2x + 5 − 2(3x − 4)4 = −4x + 134

Пример 1

Упрости 5 − 2(3 − x).

1. Раскрываем скобки: множитель −2 умножаем на каждое слагаемое.
2. −2 · 3 = −6,   −2 · (−x) = +2x.
5 − 6 + 2x = 2x − 1
Проверка на числе: при x = 1 исходное выражение равно 5 − 2 · 2 = 1, и ответ 2 · 1 − 1 = 1. Сошлось.

2. Уравнение, корень, равносильность

ОПРЕДЕЛЕНИЯ
Уравнение — равенство, которое верно только при некоторых значениях переменной. Такие значения называют корнями. Найти все корни — значит решить уравнение.

Проверить, корень ли данное число, можно всегда одинаково: подставить его вместо переменной и посмотреть, получилось ли верное равенство.

Пример 2

1. Число 4 и уравнение 20x = 10: 20 · 4 = 80, то есть 80 = 10 — неверно. Значит 4 не корень.
2. Число 4 и уравнение 5x = 20: 5 · 4 = 20, то есть 20 = 20 — верно. Значит 4 — корень.
3. Число −5 и уравнение x2 = 25: (−5)2 = 25 — верно, это корень.
4. Число −9 и уравнение x2 = −81: получаем 81 = −81 — неверно, не корень.
Квадрат любого числа неотрицателен, поэтому у такого уравнения корней не будет вовсе.
РАВНОСИЛЬНЫЕ УРАВНЕНИЯ
Два уравнения называют равносильными, если у них одни и те же корни.
5x − 25 = 0   и   2x − 7 = 3 — оба дают x = 5

3. Сколько бывает корней

У уравнения может быть один корень, несколько, ни одного или бесконечно много.

ПРОИЗВЕДЕНИЕ РАВНО НУЛЮ
Произведение равно нулю, если хотя бы один из множителей равен нулю. Поэтому каждую скобку по очереди приравнивают к нулю.
(x + 3)(x − 5)(x + 1) = 0  →  x = −3,   x = 5,   x = −1

Пример 3

1. x2 = 25 — два корня: 5 и −5.
2. x2 = −25 — корней нет: квадрат не бывает отрицательным.
3. 0x = 25 — корней нет: ноль, умноженный на любое число, даёт ноль, а не 25.
4. 0x = 0 — корней бесконечно много: подходит любое число.
5. 10x = 10x — тоже бесконечно много корней.
Если нашёл один корень и не проверил, есть ли другие, — уравнение ещё не решено.

4. Тождественные преобразования

Решение уравнения — это замена его другим уравнением, у которого те же корни. Вот что делать можно.

1. ЗАМЕНА ВЫРАЖЕНИЯ РАВНЫМ
(3x + 2)2 = 15x + 10  →  9x2 + 12x + 4 = 15x + 10.
2. ПЕРЕНОС СЛАГАЕМЫХ
Переносим через знак равно, меняя знак каждого перенесённого слагаемого: 9x2 + 12x + 4 − 15x − 10 = 0, то есть 9x2 − 3x − 6 = 0.
5x − 3y = 4x − 8y  →  5x − 4x = 3y − 8y
3. УМНОЖЕНИЕ И ДЕЛЕНИЕ НА ЧИСЛО
Обе части можно умножить или разделить на одно и то же число, не равное нулю.
9x2 − 3x − 6 = 0  | : 3  →  3x2 − x − 2 = 0
0,2t2 + 0,4t − 7 = 0  | · 5  →  t2 + 2t − 35 = 0
ЧЕГО ДЕЛАТЬ НЕЛЬЗЯ
Умножать или делить на выражение с переменной. Умножение даёт посторонний корень: у x − 1 = 0 корень один, а у (x − 1)(x − 3) = 0 их уже два. Деление теряет корень: сократив (x − 2)(x − 4) = (x − 4) на скобку, теряем x = 4.
ЧЁТНАЯ СТЕПЕНЬ
Возведение обеих частей в чётную степень может добавить посторонние корни: у 7x = 35 корень один, а у 49x2 = 1225 их два. И наоборот, неправильное извлечение корня теряет корни: из 16x2 = 64 следует x2 = 4, то есть x = 2 и x = −2.

5. Линейное уравнение

ОПРЕДЕЛЕНИЕ
Линейным уравнением с одним неизвестным называют уравнение вида ax + b = 0, где a и b — числа, а x — неизвестное. Переменная стоит в первой степени.
если a ≠ 0, то x = −ba

В простейших случаях достаточно разделить обе части на коэффициент при x.

Пример 4

1. 3x = 6  →  x = 63 = 2.
2. 25x = 34  →  x = 34 : 25 = 34 · 52 = 158.
3. 32x = 4  →  x = 4 · 23 = 83.
4. 2x = 45  →  x = 45 : 2 = 25.
Деление на дробь — это умножение на обратную к ней.

6. Алгоритм и особые случаи

АЛГОРИТМ
  1. Раскрыть все скобки.
  2. Слагаемые с переменной перенести налево, без переменной — направо, меняя знаки.
  3. Привести подобные слева и справа: получится ax = b.
  4. Найти ответ делением: x = b : a.

Пример 5

Решить 3(x − 2) + 7(4 − 2x) − 5(5 − 3x) = 4 − 6x.

1. Раскрываем скобки, особенно аккуратно третью, с множителем −5: 3x − 6 + 28 − 14x − 25 + 15x = 4 − 6x.
2. Приводим подобные слева: 4x − 3 = 4 − 6x.
3. Переносим: 4x + 6x = 4 + 3.
10x = 7  →  x = 0,7

Пример 6

Решить 3(x − 5) + 2(x − 4) = −23.

1. 3x − 15 + 2x − 8 = −23.
2. 3x + 2x = −23 + 8 + 15.
5x = 0  →  x = 0
Ноль в ответе — обычный корень. Это не «нет корней» и не повод сбиваться с алгоритма.
ДВА ОСОБЫХ СЛУЧАЯ
Если после приведения подобных переменная исчезла совсем, смотрим на то, что осталось:
0 = 0 (верное равенство) — корней бесконечно много;
0 = 13 (неверное равенство) — корней нет.

Пример 7

1. 3(x + 5) − 15 = 3x  →  3x + 15 − 15 = 3x  →  3x − 3x = 0  →  0 = 0.
Корней бесконечно много
2. 2(2x − 4) = 4(x + 3) − 7  →  4x − 8 = 4x + 12 − 7  →  4x − 4x = 8 + 12 − 7  →  0 = 13.
Корней нет
