Степень с натуральным показателем

Алгебра, 7 класс · §1 «Степень с натуральным показателем и её свойства» · 14 задач
Как работать: прочитай теорию — там два помощника, в которых свойства степени раскладываются на множители прямо у тебя на глазах. Потом разбери примеры и реши задачи. У каждой задачи есть три подсказки, они открываются по одной; открывать их не стыдно. Решения записывай в тетрадь, потом сфотографируй, приложи фото внизу страницы и нажми «Отправить на проверку».

Теория

1. Что такое степень

Определение. Степенью числа a с натуральным показателем n, большим 1, называется произведение n множителей, каждый из которых равен a. Если n = 1, то a¹ = a.
an = a · a · a · … · a   (n множителей)

Здесь an — степень, a — основание степени, n — показатель степени. Найти значение степени — значит посчитать это произведение; такое действие называют возведением в степень.

4³ = 4 · 4 · 4 = 645⁶ = 15 625

2. Знак степени и роль скобок

Степень отрицательного числа с чётным показателем — число положительное.
Степень отрицательного числа с нечётным показателем — число отрицательное.
Квадрат любого числа неотрицателен: a² ≥ 0 при любом a.

Самая частая ошибка в этой теме — потерять скобки. Подвигай числа в помощнике и посмотри, чем −an отличается от (−a)n.

3. Пять свойств степени — попробуй сам

Все свойства доказываются одинаково: степень расписывают по определению в произведение множителей, а потом собирают обратно. Выбери свойство, поменяй числа и посмотри, как это работает.

4. Все свойства в одном месте

1) am · an = am+n2) am : an = am−n3) (am)n = amn
4) (a · b)n = an · bn5) (a : b)n = an : bn
свойствокак звучитусловия
am · an основание оставляют прежним, показатели складываютлюбое a
am : an основание прежнее, из показателя делимого вычитают показатель делителя a ≠ 0, m > n
(am)n основание прежнее, показатели перемножаютлюбое a
(a · b)n в степень возводят каждый множитель, результаты перемножаютлюбые a, b

5. Нулевой показатель

Степень числа a ≠ 0 с нулевым показателем равна единице: a⁰ = 1. Выражение 0⁰ смысла не имеет.

Откуда это берётся: по второму свойству a⁹ : a⁹ = a9−9 = a⁰. Но любое число, делённое само на себя, даёт 1. Значит a⁰ = 1.

3⁰ = 1(−2,5)⁰ = 10⁰ — не имеет смысла

6. Свойства работают и в обратную сторону

Каждое свойство можно читать справа налево — это нужно, когда степень надо разложить, а не собрать.

прямообратнопример
aman = am+nam+n = aman 2¹¹ = 2⁴ · 2⁷
am:an = am−nam−n = am:an 2⁶ = 2¹⁰ : 2⁴
(am)n = amnamn = (am)n 4⁶ = (4²)³;   9³ = (3²)³
(ab)n = anbnanbn = (ab)n 0,5⁸ · 2⁸ = 1⁸ = 1
(a:b)n = an:bnan:bn = (a:b)n 12⁴ : 3⁴ = 4⁴ = 256

Обратное чтение — это и есть «рациональный способ»: вместо того чтобы считать 25³ и 0,4³ по отдельности, собираем их в (25 · 0,4)³ = 10³.

7. Порядок действий

В числовом выражении без скобок сначала выполняют возведение в степень, затем умножение и деление, и только потом сложение и вычитание.
2 · 5³ + 3 · (−2)³ = 2 · 125 + 3 · (−8) = 250 − 24 = 226

- в степени степени складывают показатели вместо умножения: (a⁴)² — это a⁸, а не a⁶;
- применяют свойства к степеням с разными основаниями: 2³ · 3³ нельзя записать как 6⁶ — правильно (2 · 3)³ = 6³.

Разобранные примеры

Семь примеров закрывают все типы задач этой домашки. Сначала попробуй сам, потом открой решение и сверься.

Пример 1. Найти значение степени

Вычислите: а) 0,3⁴; б) (−5)⁵; в) (2/3)³.

Показать решение
а) Расписываем по определению: 0,3⁴ = 0,3 · 0,3 · 0,3 · 0,3 = 0,0081.
б) (−5)⁵ = (−5)·(−5)·(−5)·(−5)·(−5). Показатель нечётный, значит результат отрицательный: −3125.
в) У дроби в степень возводятся и числитель, и знаменатель: (2/3)³ = 2³/3³ = 8/27.
0,3⁴ = 0,0081(−5)⁵ = −3125(2/3)³ = 8/27
Ответ: 0,0081; −3125; 8/27.

Пример 2. Где стоит минус

Вычислите: 4²; −4²; (−4)²; 5³; −5³; (−5)³.

Показать решение
1. 4² = 16 — обычная степень.
2. −4²: скобок нет, поэтому в степень возводится только 4, а минус остаётся снаружи: −(4²) = −16.
3. (−4)²: минус внутри скобок, в степень идёт всё число −4. Показатель чётный, результат положительный: 16.
4. Точно так же: 5³ = 125; −5³ = −(5³) = −125; (−5)³ = −125.
−4² = −16(−4)² = 16
Ответ: 16; −16; 16; 125; −125; −125.
Для нечётного показателя −5³ и (−5)³ совпали случайно. Для чётного они всегда разные — именно поэтому скобки нельзя терять.

Пример 3. Произведение степеней

Представьте в виде степени: а) 5² · 5⁴; б) (3/7)⁵ · (3/7)⁶; в) m¹⁰ · m¹⁵.

Показать решение
1. Проверяем главное условие: основания одинаковые. Тогда работает первое свойство — показатели складываются.
а) 5² · 5⁴ = 52+4 = 5⁶.
б) Основание — дробь 3/7, но правило то же: (3/7)5+6 = (3/7)¹¹.
в) m¹⁰ · m¹⁵ = m10+15 = m²⁵.
am · an = am+n
Ответ: 5⁶; (3/7)¹¹; m²⁵.
Обратное чтение того же свойства: 4⁷ = 42+5 = 4² · 4⁵. Разложить степень можно многими способами.

Пример 4. Частное степеней

Представьте в виде степени: а) 5²⁰ : 5¹⁴; б) m¹⁸ : m¹⁵; в) представьте 4⁷ в виде частного.

Показать решение
а) Основания одинаковые, показатели вычитаем: 5²⁰ : 5¹⁴ = 520−14 = 5⁶.
б) m¹⁸ : m¹⁵ = m18−15 = m³.
в) Читаем свойство наоборот: 4⁷ = 410−3 = 4¹⁰ : 4³. Подойдёт любая пара показателей с разностью 7.
am : an = am−n,   a ≠ 0
Ответ: 5⁶; m³; например, 4¹⁰ : 4³.

Пример 5. Степень степени

а) Представьте в виде степени: (5²)³ и (m⁴)⁶. б) Представьте 9³ и 81 в виде степени с основанием 3.

Показать решение
а) Показатели перемножаем: (5²)³ = 52·3 = 5⁶; (m⁴)⁶ = m4·6 = m²⁴.
б) Сначала замечаем, что 9 = 3². Тогда 9³ = (3²)³ = 32·3 = 3⁶.
Аналогично 81 = 3⁴, значит 81 = (3²)² = 3⁴.
(am)n = amn
Ответ: 5⁶; m²⁴; 3⁶; 3⁴.
Приём «привести к одному основанию» встречается постоянно: 4 = 2², 8 = 2³, 9 = 3², 27 = 3³, 25 = 5², 0,01 = 0,1².

Пример 6. Рациональный счёт

Вычислите: а) 0,5⁸ · 2⁸; б) 25³ · 0,4³; в) 10⁴ : 5⁴; г) 21⁵ : 7⁵.

Показать решение
Во всех пунктах показатели одинаковые, а основания разные — значит читаем четвёртое и пятое свойства справа налево и сначала действуем с основаниями.
а) 0,5⁸ · 2⁸ = (0,5 · 2)⁸ = 1⁸ = 1.
б) 25³ · 0,4³ = (25 · 0,4)³ = 10³ = 1000.
в) 10⁴ : 5⁴ = (10 : 5)⁴ = 2⁴ = 16.
г) 21⁵ : 7⁵ = (21 : 7)⁵ = 3⁵ = 243.
an · bn = (a · b)nan : bn = (a : b)n
Ответ: 1; 1000; 16; 243.
Считать 0,5⁸ и 2⁸ по отдельности никто не запрещает, но это долго и легко ошибиться. Смысл свойства как раз в том, чтобы этого не делать.

Пример 7. Несколько свойств подряд

а) Упростите (a⁴)² · (a³)³. б) Вычислите 2 · 5³ + 3 · (−2)³.

Показать решение
а) Сначала раскрываем скобки по свойству степени степени — показатели перемножаем: (a⁴)² = a⁸ и (a³)³ = a⁹.
Теперь это произведение степеней с одинаковым основанием, показатели складываем.
(a⁴)² · (a³)³ = a⁸ · a⁹ = a¹⁷
б) Порядок действий: сначала степени, потом умножение, потом сложение.
5³ = 125; (−2)³ = −8; 2 · 125 = 250; 3 · (−8) = −24; 250 − 24 = 226.
2 · 5³ + 3 · (−2)³ = 226
Ответ: a¹⁷; 226.

Шпаргалка

Этот блок печатается отдельно на один лист A4: Ctrl+P (⌘+P) → печать.

Определение: an = a · a · … · a (n множителей); a¹ = a. a — основание, n — показатель.

Свойства: aman = am+n; am : an = am−n (a ≠ 0, m > n); (am)n = amn; (ab)n = anbn; (a : b)n = an : bn (b ≠ 0).

Нулевой показатель: a⁰ = 1 при a ≠ 0; выражение 0⁰ смысла не имеет.

Знаки: отрицательное число в чётной степени — положительное, в нечётной — отрицательное; a² ≥ 0 всегда. Без скобок степень относится только к числу: −5² = −25, а (−5)² = 25.

Порядок действий: степень → умножение и деление → сложение и вычитание.

Обратное чтение (рациональный счёт): anbn = (ab)n; an : bn = (a : b)n; amn = (am)n. Например, 25³ · 0,4³ = 10³ = 1000 и 12⁴ : 3⁴ = 4⁴ = 256.
