Системы уравнений

Алгебра · тема 2 (2.01–2.06) · 7 тренажёров, 6 блоков с пропусками, 30 задач
Как работать. Страница идёт по кругу: короткая порция теории — разобранный пример — тренажёр или блок с пропусками — задачи. Не перепрыгивай вперёд.
Главное правило темы: сначала пробуй подстановку. Не выходит — смотри на коэффициенты: сложение, вычитание, домножение, деление. Повторяется один и тот же кусок — замена переменной.
Ответ системы — это пара чисел: сначала x, потом y. В поле на странице уходит одно число, но в тетради пиши пару целиком.
Ответы-дроби пиши через косую черту: 13/3 или −1/4. Где ответ десятичный, так и пиши: −0,5.
Все семь тренажёров и все шесть блоков с пропусками нужно пройти до конца — без этого работа не отправится.

Памятка: всё, что понадобится

Сюда возвращаются, когда застряли. Читать целиком сразу не нужно.

Основа

Что такое система

{x + y = 15x − y = 1

Несколько уравнений, которые должны выполняться одновременно. Их объединяют фигурной скобкой.

Решение — пара чисел, подходящая сразу ко всем уравнениям.

Как записывают ответ

(2; 1)

Сначала x, потом y, через точку с запятой.

Сколько пар — столько и решений. Пары путать нельзя.

Первый метод — подстановка

Выражаем одну переменную из одного уравнения и подставляем в другое.

Выражать нужно ту, которая выражается проще: без дробей.

Работает всегда, с него и начинают.

Линейные системы

Сложение

{3x − 2y = 55x + 2y = 19

Коэффициенты при y равны по модулю и противоположны по знаку — складываем уравнения, y исчезает.

Получаем 8x = 24, дальше просто.

Вычитание

{4x − 3y = 54x + 2y = −10

Коэффициенты при x одинаковы и по модулю, и по знаку — вычитаем.

Надёжнее домножить одно уравнение на −1 и всё-таки сложить: при вычитании легко ошибиться в знаках.

Домножение

{5x + 11y = 810x − 7y = 74

Коэффициенты разные — домножаем одно уравнение так, чтобы они сравнялись.

Здесь достаточно умножить первое на 2.

Сколько решений у линейной системы

Одно решение

Коэффициенты при x и y не пропорциональны.

a₁a₂ ≠ b₁b₂

Прямые пересекаются в одной точке.

Решений нет

{2x − 3y = 76x − 9y = 12

Коэффициенты пропорциональны, а свободные члены — нет.

После деления получаются противоречивые уравнения.

Бесконечно много

{10x + 14y = 4215x + 21y = 63

Пропорциональны все три числа, включая свободный член.

Фактически это одно уравнение, записанное дважды.

Нелинейные системы

Расщепление

A · B = 0 ⟺ A = 0 или B = 0

Если одно уравнение удалось разложить на множители, система распадается на две.

Сокращать на скобку с переменной нельзя — потеряешь корни.

Сложение в нелинейных

{x2 + xy = 15y2 + xy = 10

Складываем и получаем (x + y)2 = 25.

Смотри на пару ходов вперёд: часто складывается формула сокращённого умножения.

Деление

Делят, когда в обоих уравнениях есть один и тот же множитель.

При делении он сокращается, и остаётся простая связь между x и y.

Делить можно только на выражение, не равное нулю.

Замена и порядок

Замена переменных

{xy + yx = 136x + y = 5

Пусть xy = t — первое уравнение станет квадратным относительно t.

После замены не забудь вернуться к x и y.

Порядок действий

1. Попробовать подстановку — она проще всего.

2. Не вышло — сложение, вычитание, деление.

3. Увидел повторяющийся кусок — замена.

4. Записать все пары, ничего не перепутав.

Частые ошибки

Найти x и забыть найти y.

Перепутать пары, когда решений несколько.

Сократить на переменную и потерять решение.

1. Что такое система и метод подстановки

Начнём с задачи: найти два числа, сумма которых равна 15, а разность — 1. Одно условие даёт уравнение x + y = 15, второе — x − y = 1. Выполняться они должны одновременно, и чтобы это показать, их объединяют фигурной скобкой.

{x + y = 15x − y = 1
ОПРЕДЕЛЕНИЯ
Несколько связанных друг с другом уравнений называют системой уравнений.
Решение системы с двумя неизвестными — пара значений переменных, которая является решением каждого уравнения системы одновременно.
КАК ЗАПИСЫВАЮТ ОТВЕТ
Парой чисел в скобках: на первом месте x, на втором y. Сколько получилось пар — столько у системы решений.
МЕТОД ПОДСТАНОВКИ
В одном из уравнений выражаем одну переменную через другую и подставляем это выражение в остальные уравнения системы.

Пример 1

Решить систему {3x − 2y = 4x + 3y = 5.

1. Из первого уравнения выразим x: x = 2y + 43.
2. Подставим во второе: 2y + 43 + 3y = 5.
3. Решаем и находим y = 1.
4. Возвращаемся к выражению для x: x = 2 · 1 + 43 = 2.
Ответ: (2; 1)
Проверка: 3 · 2 − 2 · 1 = 4 и 2 + 3 · 1 = 5. Обе строчки сошлись.
ОЧЕНЬ ВАЖНОЕ ЗАМЕЧАНИЕ
Прежде чем выражать переменную, посмотри, какую и из какого уравнения выражать проще. В примере выше удобнее было взять второе уравнение и выразить x = 5 − 3y — тогда дробей вообще не появилось бы.

Пример 2

Решить систему {2x + 3y = 104x − y = 6.

1. Мы лентяи и ищем самое простое. Легче всего выразить y из второго уравнения: y = 4x − 6.
2. Подставляем в первое: 2x + 3(4x − 6) = 10.
3. 2x + 12x − 18 = 10, то есть 14x = 28 и x = 2.
4. y = 4 · 2 − 6 = 2.
Ответ: (2; 2)
Перед y стоит коэффициент −1 — именно такую переменную и ищут глазами: при ней не появится дробь.

2. Скобки и дроби: сначала порядок

Если в системе есть скобки или дроби, её сначала приводят к привычному виду «числа при x, числа при y, свободный член справа». Методы после этого те же самые.

Пример 3. Скобки

Решить систему {−2(x − y) + 16 = 3(7 + y)6x − (x − 5) = −(1 + y) − 8.

1. Раскрываем скобки в обоих уравнениях: −2x + 2y + 16 = 21 + 3y и 6x − x + 5 = −1 − y − 8.
2. Приводим подобные: −2x − y = 5 и 5x + y = −14.
3. Теперь коэффициенты при y противоположны — складываем: 3x = −9, x = −3.
4. Из второго уравнения y = −14 − 5 · (−3) = 1.
Ответ: (−3; 1)
Минус перед скобкой меняет знак у каждого слагаемого внутри — здесь теряют знаки чаще всего.

Пример 4. Дроби

Решить систему {2x5 + y3 = 1x10 − 7y6 = 4.

1. Приводим каждое уравнение к общему знаменателю: 6x + 5y15 = 1 и 3x − 35y30 = 4.
2. Умножаем на знаменатели: 6x + 5y = 15 и 3x − 35y = 120.
3. Дальше как обычно: домножим второе на 2 и вычтем, получим y = −3, затем x = 5.
Ответ: (5; −3)
Дроби убирают сразу: умножение обеих частей на знаменатель законно и сильно упрощает жизнь.

3. Сложение, вычитание и домножение

СЛОЖЕНИЕ
Если коэффициенты при одной переменной равны по величине, но противоположны по знаку, складываем левые и правые части. Эта переменная исчезает.

Пример 5

Решить систему {3x − 2y = 55x + 2y = 19.

1. В первом уравнении −2y, во втором +2y — при сложении они дадут нуль.
2. 3x − 2y + 5x + 2y = 5 + 19, то есть 8x = 24 и x = 3.
3. Подставляем в первое: 3 · 3 − 2y = 5, откуда y = 2.
Ответ: (3; 2)
ВЫЧИТАНИЕ
Если коэффициенты при переменной равны и по величине, и по знаку, вычитаем одно уравнение из другого.
ЗДЕСЬ ЛЕГКО ОШИБИТЬСЯ В ЗНАКАХ
При вычитании скобку раскрывают целиком: 4x − 3y − (4x + 2y) = 5 − (−10). Надёжнее домножить одно уравнение на −1 и всё-таки сложить.

Пример 6

Решить систему {4x − 3y = 54x + 2y = −10.

1. Вычитаем второе из первого: 4x − 3y − 4x − 2y = 5 + 10.
2. −5y = 15, значит y = −3.
3. Подставляем в первое: 4x − 3 · (−3) = 5, то есть 4x + 9 = 5 и 4x = −4.
Ответ: (−1; −3)
Проверка: 4 · (−1) + 2 · (−3) = −10. Сошлось.
В ПОСОБИИ ЗДЕСЬ ОПЕЧАТКА
В образце этого примера напечатан ответ (7/2; −3). Это неверно: при подстановке y = −3 получается 4x + 9 = 5, а не 4x − 9 = 5. Правильный ответ — (−1; −3), и он проходит проверку по обоим уравнениям.
ДОМНОЖЕНИЕ
Если коэффициенты разные, домножаем одно уравнение (или оба) так, чтобы коэффициенты при какой-нибудь переменной сравнялись.

Пример 7

Решить систему {5x + 11y = 810x − 7y = 74.

1. Видим, что 10 = 5 · 2 — умножаем первое уравнение на 2.
2. 10x + 22y = 16 и 10x − 7y = 74.
3. Вычитаем: 29y = −58, значит y = −2.
4. 5x + 11 · (−2) = 8, откуда x = 6.
Ответ: (6; −2)

Пример 8. Когда множитель не один

Решить систему {3x − 93 = 5y−103 + 5x − 4y = 0.

1. Сначала наведём порядок: 3x − 5y = 93 и 5x − 4y = 103.
2. Целого множителя нет, поэтому домножаем оба: первое на 5, второе на 3 — тогда при x получится 15.
3. 15x − 25y = 465 и 15x − 12y = 309.
4. Вычитаем второе из первого: −25y + 12y = 465 − 309, то есть −13y = 156 и y = −12.
5. 3x − 5 · (−12) = 93, откуда 3x = 33 и x = 11.
Ответ: (11; −12)
Проверка подстановкой: 3 · 11 − 5 · (−12) = 93 и 5 · 11 − 4 · (−12) = 103. Сошлось.
И ЗДЕСЬ В ПОСОБИИ ОПЕЧАТКА
В образце напечатано 15x − 20y = 309, хотя при умножении второго уравнения на 3 получается 15x − 12y = 309 (ведь 3 · 4 = 12). С двадцаткой ответ (11; −12) не получился бы.

4. Три варианта линейной системы

Не у всякой системы ровно одно решение. Посмотрим на два особых случая.

Пример 9. Бесконечно много решений

Система {10x + 14y = 4215x + 21y = 63.

1. Все коэффициенты пропорциональны: 1015 = 1421 = 4263 = 23.
2. Разделим первое уравнение на 2, а второе — на 3.
3. Получатся два одинаковых уравнения 5x + 7y = 21.
Бесконечно много решений
Фактически это одно уравнение с двумя неизвестными: какое x ни возьми, подходящий y найдётся.

Пример 10. Решений нет

Система {2x − 3y = 76x − 9y = 12.

1. Коэффициенты при x и y пропорциональны: 26 = −3−9 = 13.
2. А свободные члены — нет: 712 ≠ 13.
3. Разделим второе уравнение на 3: 2x − 3y = 4.
4. Получилось, что одно и то же выражение равно и 7, и 4.
Решений нет
Уравнения противоречат друг другу — такого не бывает ни при каких x и y.

5. Подстановка в нелинейных системах

Метод тот же, но после подстановки получается не линейное, а квадратное или дробно-рациональное уравнение. А значит, решений может быть несколько.

ГЛАВНОЕ ПРАВИЛО
Если решений больше одного, пары надо записать не перепутав. Каждому найденному значению одной переменной отвечает своё значение другой.

Пример 11

Решить систему {y = 35xy2 − xy = −6.

1. Подставляем y из первого уравнения во второе: (35x)2 − x · 35x = −6.
2. 925x2 − 35x2 = −6, после приведения 625x2 = 6.
3. x2 = 25, значит x = 5 или x = −5.
4. Каждому x отвечает свой y: при x = 5 получаем y = 3, при x = −5 получаем y = −3.
Ответ: (5; 3) и (−5; −3)

Пример 12

Решить систему {x2 + y2 + 6x + 2y = 0x + y + 8 = 0.

1. Из второго уравнения x = −y − 8.
2. Подставляем: (−y − 8)2 + y2 + 6(−y − 8) + 2y = 0.
3. Замечаем, что (−y − 8)2 = (y + 8)2 — знаки внутри скобки можно поменять, если степень чётная.
4. y2 + 16y + 64 + y2 − 6y − 48 + 2y = 0, то есть 2y2 + 12y + 16 = 0.
5. y2 + 6y + 8 = 0 даёт y = −2 и y = −4.
6. Возвращаемся: x = −y − 8 даёт x = −6 и x = −4.
Ответ: (−6; −2) и (−4; −4)
Обрати внимание на порядок: y = −2 идёт в паре с x = −6, а не с −4.

Пример 13. Три переменные

Решить систему {2x + y + z = 7x + 2y + z = 8x + y + 2z = 9.

1. Из первых двух уравнений выражаем z: z = 7 − 2x − y и z = 8 − x − 2y.
2. Приравниваем: 7 − 2x − y = 8 − x − 2y, откуда y = x + 1.
3. Подставляем во все уравнения и приходим к системе из двух уравнений с двумя неизвестными.
4. Решая её, получаем z = 3, x = 1, y = 2.
Ответ: (1; 2; 3)
Систему с тремя переменными сводят к системе с двумя — и решают уже знакомым способом.

6. Расщепление системы и сложение уравнений

РАСЩЕПЛЕНИЕ
Если одно из уравнений удалось представить в виде произведения, равного нулю, оно распадается на два. Каждое из них составляет пару со вторым уравнением системы — и вместо одной сложной системы получаются две простые.

Пример 14

Решить систему {x2 − xy = 4x − 4y2x2 − xy − 4 = 0.

1. В первом уравнении выносим общие множители: x(x − y) = 4(x − y).
2. Переносим всё влево: (x − y)(x − 4) = 0.
3. Значит x = y или x = 4.
4. Первый случай: 2x2 − x2 − 4 = 0, то есть x2 = 4 и x = ±2.
5. Второй случай: 2 · 16 − 4y − 4 = 0, откуда y = 7.
Ответ: (2; 2), (−2; −2) и (4; 7)
САМАЯ ДОРОГАЯ ОШИБКА ТЕМЫ
Ни в коем случае не сокращай на скобку с переменной. Если в примере выше разделить обе части на (x − y), останется только x = 4, а две пары решений пропадут.
СЛОЖЕНИЕ В НЕЛИНЕЙНЫХ СИСТЕМАХ
Складывают тогда, когда после сложения получается что-то заметно более простое — например, формула сокращённого умножения.

Пример 15

Решить систему {x2 + xy = 15y2 + xy = 10.

1. Складываем уравнения: x2 + 2xy + y2 = 25.
2. Слева — квадрат суммы: (x + y)2 = 25.
3. Отсюда x + y = 5 или x + y = −5 — получаем две простые системы.
4. Решая их, находим пары (3; 2) и (−3; −2).
Ответ: (3; 2) и (−3; −2)
Второй корень квадратного уравнения забывать нельзя: систем получается именно две.

Пример 16

Решить систему {x2 + y2 = 20xy = 8.

1. Домножаем второе уравнение на 2: 2xy = 16.

7. Деление уравнений

КОГДА ДЕЛЯТ
Когда в обоих уравнениях есть один и тот же множитель. При делении он сокращается, и остаётся простая связь между переменными.

Пример 17

Решить систему {x + y = 3x3 + x2y = 12.

1. Во втором уравнении выносим x2 за скобки: x2(x + y) = 12.
2. Делим второе уравнение на первое: x2(x + y)x + y = 123.
3. Скобка сокращается: x2 = 4, значит x = 2 или x = −2.
4. Из первого уравнения находим y: y = 1 и y = 5.
Ответ: (2; 1) и (−2; 5)
То же самое можно было сделать подстановкой x + y = 3 во второе уравнение — результат тот же.

Пример 18

Решить систему {(x − y)xy = 30(x + y)xy = 120.

1. Делим второе уравнение на первое: (x + y)xy(x − y)xy = 12030.
2. Произведение xy сокращается: x + yx − y = 41.
3. Крест-накрест: x + y = 4x − 4y, то есть 3x = 5y и y = 35x.
4. Подставляем во второе уравнение и получаем x3 = 125, то есть x = 5, y = 3.
Ответ: (5; 3)

8. Замена переменных

ИДЕЯ
Если в системе несколько раз повторяется одно и то же выражение, его обозначают буквой. Система становится простой, а в конце делают обратную замену.

Пример 19

Решить систему {xy + yx = 136x + y = 5.

1. Пусть xy = t. Тогда yx — это 1t.
2. Первое уравнение: t + 1t = 136, то есть 6t2 − 13t + 6 = 0.
3. Корни t = 23 и t = 32.
4. Возвращаемся: y = 32x или y = 23x. Вместе с x + y = 5 получаем две простые системы.
Ответ: (2; 3) и (3; 2)
Первое уравнение после замены больше не нужно: связь между x и y уже получена.

Пример 20

Решить систему {x(x + 1)(3x + 5y) = 144x2 + 4x + 5y = 24.

1. В первом уравнении вносим x в первую скобку: (x2 + x)(3x + 5y) = 144.
2. Во втором раскладываем 4x на x и 3x: x2 + x + 3x + 5y = 24.
3. Пусть x2 + x = a и 3x + 5y = b. Система принимает вид {ab = 144a + b = 24.
4. Отсюда a = 12 и b = 12.
5. Обратная замена: x2 + x = 12 даёт x = 3 и x = −4, а 3x + 5y = 12 — соответствующие y.
Ответ: (3; 0,6) и (−4; 4,8)
Замену придумывают не наугад: сначала смотрят, какой кусок повторяется в обоих уравнениях.

Шпаргалка

Печатается на один лист A4: Ctrl+P (⌘+P) → печать.

Система. Несколько уравнений под фигурной скобкой, которые выполняются одновременно. Решение — пара чисел, ответ записывают как (x; y).

Подстановка. Выражаем переменную с коэффициентом 1 и подставляем в другое уравнение. Пробовать этот метод нужно первым.

Сложение. Коэффициенты равны по модулю и противоположны по знаку — складываем уравнения, переменная исчезает.

Вычитание. Коэффициенты совпадают полностью — вычитаем, раскрывая скобку целиком. Надёжнее домножить одно уравнение на −1 и сложить.

Домножение. Коэффициенты разные — умножаем уравнение (или оба) так, чтобы они сравнялись.

Три варианта линейной системы. Коэффициенты не пропорциональны — одно решение. Пропорционально всё, включая свободные члены — бесконечно много. Коэффициенты пропорциональны, а свободные члены нет — решений нет.

Расщепление. Произведение равно нулю ⟺ нулю равен один из множителей. Сокращать на скобку с переменной нельзя — потеряешь корни.

Сложение в нелинейных. Складывают, когда собирается формула сокращённого умножения: x2 + 2xy + y2 = (x + y)2.

Деление. Делят, когда в обоих уравнениях есть общий множитель: он сокращается, остаётся простая связь между x и y.

Замена. Повторяющийся кусок обозначают буквой, решают простую систему и делают обратную замену.

Порядок действий. 1) подстановка; 2) сложение, вычитание, домножение, деление; 3) замена; 4) выписать все пары, не перепутав.
