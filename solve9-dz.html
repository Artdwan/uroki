Решение прямоугольных треугольников

Геометрия, 9 класс · §2 · домашнее задание · 14 задач
Как работать: прочитай теорию, разбери семь примеров, реши задачи. У каждой задачи есть три подсказки — они открываются по одной и ведут от идеи к вычислению; открывать их не стыдно. Для углов вроде 32° внизу теории есть таблица значений. Решения записывай в тетрадь с чертежом, потом сфотографируй, приложи фото внизу страницы и нажми «Отправить на проверку».

Теория

1. Что значит «решить треугольник»

Решить прямоугольный треугольник — значит найти все его неизвестные стороны и углы по нескольким известным элементам.

Договоримся об обозначениях: ∠C = 90°, катет a лежит против угла α, катет b прилежит к углу α, c — гипотенуза. Один элемент известен всегда: сумма острых углов прямоугольного треугольника равна 90°.

α + β = 90°

2. Четыре рабочие формулы

Все они получаются из определений синуса, косинуса и тангенса — надо только выразить из них нужную сторону.

a = c · sin αb = c · cos αa = b · tg α
c = a : sin αc = b : cos α
правило словамиформула
катет = гипотенуза × синус противолежащего углаa = c · sin α
катет = гипотенуза × косинус прилежащего углаb = c · cos α
катет = другой катет × тангенс угла, противолежащего первомуa = b · tg α
гипотенуза = катет : синус противолежащего углаc = a : sin α
гипотенуза = катет : косинус прилежащего углаc = b : cos α
Главный вопрос при выборе формулы всегда один: как известный катет расположен относительно данного угла — противолежит ему или прилежит. Ответ на этот вопрос и решает, что писать: синус, косинус или тангенс.

3. Пять случаев — вся тема в одной таблице

даночто делаем
a и bc = √(a² + b²);   tg α = a : b → α по таблице;   β = 90° − α
a и cb = √(c² − a²);   sin α = a : c → α по таблице;   β = 90° − α
c и αβ = 90° − α;   a = c · sin α;   b = c · cos α
a и αβ = 90° − α;   c = a : sin α;   b = a · ctg α
a и βα = 90° − β;   c = a : cos β;   b = a · tg β

Коротко: даны две стороны — начинай с теоремы Пифагора, потом угол. Дана сторона и угол — начинай со второго угла, потом стороны.

4. Два треугольника, которые надо знать наизусть

Углы 30° и 60°. Против угла 30° лежит меньший катет, и он равен половине гипотенузы. Больший катет получается из меньшего умножением на √3.

Угол 45°. Треугольник равнобедренный: катеты равны, а гипотенуза больше катета в √2 раза. Обратно: катет равен гипотенузе, делённой на √2.

В этих двух случаях таблица значений не нужна вообще — ответ получается точным, с корнями, а не приближённым.

5. Площадь и тригонометрия

Площадь прямоугольного треугольника — это половина произведения катетов. А если угол между сторонами не прямой, работает общая формула:

S = ½ · a · bS = ½ · a · b · sin α

Вторая формула — это та же первая, только вместо второго катета подставлена высота, найденная через синус. Именно так решаются задачи 13 и 14.

6. Таблица значений

Для углов вроде 32° или 68° значения берут из таблиц или с калькулятора. Впиши угол — получишь все четыре значения сразу.

° от 1° до 89°

cos√3/2 ≈ 0,87√2/2 ≈ 0,710,5

Три ловушки, на которых теряют баллы:
- путают противолежащий катет с прилежащим и берут синус вместо косинуса;
- умножают там, где надо делить: гипотенуза всегда больше каждого катета;
- забывают округлить так, как просят в условии (стороны до десятых, углы до градуса).

Разобранные примеры

Семь примеров закрывают все типы задач этой домашки. Сначала попробуй решить сам, потом открой решение и сверься — важно не только число, но и выбор формулы.

Пример 1. Дана гипотенуза и угол

Гипотенуза прямоугольного треугольника равна 6, острый угол равен 32°. Найти катет, прилежащий к данному углу. Ответ округлить до 0,1.

Показать решение
1. Искомый катет прилежит к данному углу, а известна гипотенуза — значит работает косинус.
2. Записываем формулу и подставляем: x = 6 · cos 32°.
3. По таблице cos 32° ≈ 0,8480.
x = 6 · 0,8480 ≈ 5,088 ≈ 5,1
Ответ: 5,1.
Проверка смыслом: катет должен быть меньше гипотенузы. 5,1 < 6 — сходится.

Пример 2. Дан катет и прилежащий угол

Катет прямоугольного треугольника равен 2,5, прилежащий к нему острый угол равен 68°. Найти другой катет. Ответ округлить до 0,1.

Показать решение
1. Известен катет и угол при нём, ищем второй катет. Два катета и угол связывает тангенс.
2. Искомый катет противолежит данному углу, значит x = 2,5 · tg 68°.
3. По таблице tg 68° ≈ 2,4751.
x = 2,5 · 2,4751 ≈ 6,188 ≈ 6,2
Ответ: 6,2.
Тангенс большого угла больше единицы, поэтому противолежащий катет и получился больше данного.

Пример 3. Дан катет и противолежащий угол

Катет прямоугольного треугольника равен 4,2, противолежащий ему угол равен 29°. Найти гипотенузу. Ответ округлить до 0,1.

Показать решение
1. Катет противолежит углу, ищем гипотенузу — это синус: sin α = a : c.
2. Выражаем гипотенузу: c = a : sin α, то есть x = 4,2 : sin 29°.
3. По таблице sin 29° ≈ 0,4848.
x = 4,2 : 0,4848 ≈ 8,663 ≈ 8,7
Ответ: 8,7.
Здесь деление, а не умножение: гипотенуза больше катета. Если в ответе гипотенуза вышла меньше катета — перепутано действие.

Пример 4. Даны два катета — решаем целиком

Катеты прямоугольного треугольника равны 8 и 5. Найти гипотенузу и оба острых угла. Стороны округлить до 0,1, углы — до 1°.

Показать решение
1. Углы неизвестны, зато известны обе стороны — начинаем с теоремы Пифагора.
c = √(8² + 5²) = √(64 + 25) = √89 ≈ 9,4
2. Теперь угол. Известны оба катета, поэтому удобен тангенс: tg α = a : b = 8 : 5 = 1,6.
3. По таблице значению 1,6 отвечает угол α ≈ 58°.
4. Второй угол находим вычитанием: β = 90° − 58° = 32°.
c ≈ 9,4α ≈ 58°β ≈ 32°
Ответ: c ≈ 9,4; α ≈ 58°; β ≈ 32°.

Пример 5. Особые треугольники без таблицы

а) Меньший катет равен 5 и лежит против угла 30°. Найти гипотенузу и больший катет. б) Катет равен 3, прилежащий угол 45°. Найти гипотенузу.

Показать решение
а) Против угла 30° лежит половина гипотенузы, поэтому c = 2 · 5 = 10.
Больший катет: b = a · √3 = 5√3 ≈ 8,7. Можно и по Пифагору: √(100 − 25) = √75 = 5√3 — тот же ответ.
c = 10b = 5√3 ≈ 8,7
б) При угле 45° треугольник равнобедренный: второй катет тоже 3, а гипотенуза равна катету, умноженному на √2.
c = 3√2 ≈ 4,2
Ответ: а) 10 и 5√3 ≈ 8,7; б) 3√2 ≈ 4,2.
В этих двух треугольниках ответ записывают точно, с корнями, и округляют только если об этом просят.

Пример 6. Площадь через синус

Боковая сторона равнобедренного треугольника равна 15, синус угла при вершине равен 0,8. Найти площадь треугольника.

Показать решение
1. Проведём высоту к боковой стороне. Она попадает в прямоугольный треугольник, где гипотенуза — вторая боковая сторона (15), а высота противолежит углу при вершине.
2. h = 15 · sin α = 15 · 0,8 = 12.
3. Площадь — половина произведения стороны на высоту, проведённую к ней.
S = ½ · 15 · 12 = 90
Ответ: 90.
Та же выкладка одной строкой: S = ½ · a · b · sin α, где a и b — стороны, а α — угол между ними. Эту формулу стоит запомнить.

Пример 7. Тригонометрия внутри трапеции

В равнобедренной трапеции ABCD меньшее основание BC = 7, боковая сторона AB = 10, sin A = 0,8. Найти площадь трапеции.

Показать решение
1. Площадь трапеции: S = (a + b) : 2 · h. Значит нужны большее основание и высота. Проведём высоты BH и CK.
2. Появился прямоугольный треугольник ABH. Высота BH противолежит углу A, поэтому BH = AB · sin A = 10 · 0,8 = 8.
3. Второй катет по теореме Пифагора: AH = √(10² − 8²) = √36 = 6.
4. HBCK — прямоугольник, значит HK = BC = 7. Треугольники ABH и DCK равны (по катету и гипотенузе), поэтому KD = AH = 6.
5. Большее основание: AD = 6 + 7 + 6 = 19.
S = (7 + 19) : 2 · 8 = 13 · 8 = 104
Ответ: 104.
Приём общий для всей темы: увидеть прямоугольный треугольник внутри фигуры и решить его. Высоты, диагонали и апофемы почти всегда такие треугольники создают.

Обозначения: ∠C = 90°, a — катет против угла α, b — катет при угле α, c — гипотенуза. Всегда α + β = 90°.

Стороны: a = c · sin α;   b = c · cos α;   a = b · tg α;   b = a · ctg α;   c = a : sin α;   c = b : cos α.

Углы: sin α = a : c;   cos α = b : c;   tg α = a : b;   ctg α = b : a. Значение угла — по таблице или калькулятору.

Пять случаев: даны две стороны → Пифагор, затем угол через тангенс или синус. Дана сторона и угол → сначала второй угол, потом стороны.

Особые треугольники. Углы 30° и 60°: меньший катет равен половине гипотенузы, а больший катет равен меньшему, умноженному на √3. Углы 45° и 45°: катеты равны, гипотенуза равна катету, умноженному на √2.

Площадь: S = ½ · a · b для катетов; S = ½ · a · b · sin α — для любых двух сторон и угла между ними.
