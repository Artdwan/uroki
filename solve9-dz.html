Три пары формул

1 · Катет через гипотенузу

a = c · sin α
b = c · cos α

Катет равен гипотенузе, умноженной на синус противолежащего или на косинус прилежащего угла.

2 · Гипотенуза через катет

c = asin α
c = bcos α

Гипотенуза равна катету, делённому на синус противолежащего или на косинус прилежащего угла.

Делим, а не умножаем: гипотенуза — самая длинная сторона.

3 · Катет через катет

a = b · tg α
b = a · ctg α

Катет равен другому катету, умноженному на тангенс противолежащего или на котангенс прилежащего к первому катету угла.

Углы, особые случаи, проверки

Второй острый угол

β = 90° − α

Сумма острых углов прямоугольного треугольника равна 90°.

Это первое, что стоит написать, когда дан угол.

Особые углы

против 30° — половина гипотенузы
b = a√3   при углах 30° и 60°
c = a√2   при угле 45°

Здесь калькулятор не нужен — считается точно.

Проверки

Гипотенуза должна выйти длиннее каждого катета.

Против большего угла лежит большая сторона.

a2 + b2 = c2

И обязательно: теорема Пифагора должна сойтись.

1. Что значит «решить треугольник»

ОПРЕДЕЛЕНИЕ
Решить прямоугольный треугольник — значит найти все его неизвестные стороны и углы по тем данным, которые есть.

Данных всегда хватает, если известны два элемента и хотя бы один из них — сторона. Прямой угол считается известным заранее.

ЯЗЫК ЧЕРТЕЖА
Названия сторон зависят от того, про какой острый угол идёт речь. Для угла α: катет a — противолежащий, катет b — прилежащий, сторона c — гипотенуза. Для угла β всё наоборот: a становится прилежащим, а b — противолежащим.
β = 90° − α

Поэтому первое действие почти в любой задаче — отметить на чертеже данный угол и подписать стороны относительно именно него.

Пример 1

В треугольнике ABC угол C прямой, ∠A = 35°. Чему равен ∠B и какой катет противолежит углу B?

1. ∠B = 90° − 35° = 55°.
2. Углу B противолежит катет AC — он же прилежащий к углу A.
∠B = 55°, противолежащий катет — AC
Один и тот же катет называется по-разному в зависимости от угла. Это и есть источник большинства ошибок в теме.
Тренажёр 1. Кто есть кто
Восемь чертежей. Называем сторону относительно отмеченного угла.

2. Катет через гипотенузу

Из определения синуса sin α = ac сразу получаем формулу для катета.

ПРАВИЛО
Катет равен гипотенузе, умноженной на синус противолежащего угла или на косинус прилежащего угла.
a = c · sin α
b = c · cos α

Пример 2

Гипотенуза равна 6, острый угол 32°. Найди катет, прилежащий к этому углу. Ответ округли до 0,1.

1. Прилежащий катет — значит работает косинус: b = c · cos α.
2. Подставляем: b = 6 · cos 32°.
3. По таблице cos 32° ≈ 0,8480.
b ≈ 6 · 0,8480 ≈ 5,1
Проверка на здравый смысл: катет вышел меньше гипотенузы 6 — так и должно быть. Если получилось больше, перепутан синус с косинусом.

3. Гипотенуза через катет

Ту же формулу можно повернуть: если катет равен произведению, то гипотенуза равна частному.

ПРАВИЛО
Гипотенуза равна катету, делённому на синус противолежащего угла или на косинус прилежащего угла.
c = asin α
c = bcos α

Пример 3

Катет равен 4,2, противолежащий ему угол равен 29°. Найди гипотенузу. Ответ округли до 0,1.

1. Известен противолежащий катет — работает синус: sin 29° = 4,2c.
2. Отсюда c = 4,2sin 29°.
3. По таблице sin 29° ≈ 0,4848.
c ≈ 4,20,4848 ≈ 8,7
Синус острого угла меньше единицы, поэтому деление на него увеличивает число. Гипотенуза обязана выйти длиннее катета.

4. Катет через катет

Когда гипотенуза ни дана, ни нужна, катеты связывает тангенс: tg α = ab.

ПРАВИЛО
Катет равен другому катету, умноженному на тангенс противолежащего первому катету угла или на котангенс прилежащего к нему угла.
a = b · tg α
b = a · ctg α

Пример 4

Катет равен 2,5, прилежащий к нему угол равен 68°. Найди другой катет. Ответ округли до 0,1.

1. Искомый катет противолежит углу 68°, значит tg 68° = x2,5.
2. Отсюда x = 2,5 · tg 68°.
3. По таблице tg 68° ≈ 2,4751.
x ≈ 2,5 · 2,4751 ≈ 6,2
Тангенс угла больше 45° больше единицы — катет против такого угла выходит длиннее второго. Это удобная проверка.

ПОРЯДОК ДЕЙСТВИЙ
1. Обозначить искомую сторону за x. 2. Написать, чему равна нужная функция данного угла. 3. Выразить x и посчитать.

Пример 5

В треугольнике MPK известно: ∠M = 90°, ∠K = 60°, PK = 8. Найди MP и MK.

1. Прямой угол при M, значит PK — гипотенуза.
2. MP противолежит углу K: MP = PK · sin K = 8 · sin 60°.
3. MK прилежит к углу K: MK = PK · cos K = 8 · cos 60°.
MP = 8 · √32 = 4√3,   MK = 8 · 12 = 4
Углы 30°, 45° и 60° считаются точно — калькулятор тут не нужен.

    6. Особые углы: 30°, 45°, 60°

    ПОЛЕЗНО ЗАПОМНИТЬ
    Катет, лежащий против угла 30°, равен половине гипотенузы. Если меньший катет равен a, то больший равен a√3. Если дан больший катет b, то меньший равен b√3.
    УГОЛ 45°
    Оба катета равны, а гипотенуза равна a√2. Обратно: если дана гипотенуза c, то каждый катет равен c√2.

    Пример 6

    Катет, лежащий против угла 30°, равен 5. Найди гипотенузу и второй катет.

    1. Против 30° лежит половина гипотенузы, значит c = 2 · 5 = 10.
    2. Второй катет: b = a√3 = 5√3.
    c = 10,   b = 5√3 ≈ 8,7
    Проверка Пифагором: 25 + 75 = 100. Сошлось.

    7. Решаем треугольник целиком

    АЛГОРИТМ
    1. Записать, что дано, и отметить это на чертеже.
    2. Если дан угол — сразу найти второй: β = 90° − α.
    3. Найти недостающие стороны по формулам из памятки.
    4. Проверить теоремой Пифагора.

    Когда даны обе стороны, углы находят по таблице: например, из tg α = ab определяют сам угол.

    ВЫСОТА К ГИПОТЕНУЗЕ
    Площадь треугольника можно посчитать двумя способами: через катеты и через гипотенузу с высотой. Отсюда удобная формула.
    S = a · b2 = c · h2,   h = a · bc

    Пример 7

    Катеты прямоугольного треугольника равны 6 и 8. Найди гипотенузу, площадь, периметр и высоту, проведённую к гипотенузе.

    1. Гипотенуза: c = √(36 + 64) = √100 = 10.
    2. Площадь: S = 6 · 8 : 2 = 24.
    3. Периметр: P = 6 + 8 + 10 = 24.
    4. Высота: h = 6 · 810 = 4,8.
    c = 10, S = 24, P = 24, h = 4,8
    Совпадение площади и периметра здесь случайное — просто удобные числа. А вот высота всегда меньше каждого катета.

    8. Прямоугольный треугольник внутри фигуры

    ГЛАВНЫЙ ПРИЁМ
    В трапеции, параллелограмме или равнобедренном треугольнике проводят высоту — и сразу появляется прямоугольный треугольник, к которому применимы все формулы параграфа.

    Пример 8

    В равнобедренной трапеции ABCD меньшее основание BC = 7, боковая сторона AB = 10, sin A = 0,8. Найди площадь трапеции.

    1. Проведём высоты BH и CK. Тогда HK = BC = 7, а AH = KD.
    2. Из треугольника AHB: BH = AB · sin A = 10 · 0,8 = 8.
    3. AH = √(100 − 64) = 6 — знакомая тройка 6, 8, 10.
    4. Большее основание: AD = 2 · 6 + 7 = 19.
    S = 7 + 192 · 8 = 104
    Тот же приём работает в параллелограмме: высота отсекает прямоугольный треугольник, в котором известны сторона и угол.
