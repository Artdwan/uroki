Графики y = f(|x|) и y = |f(x)|

Два модуля — два разных зеркала. Один отражает график в вертикальной оси, другой в горизонтальной. Вся тема держится на том, чтобы не перепутать, какой именно модуль стоит в формуле.

1. Модуль у аргумента: y = f(|x|)

Запишем модуль по определению и подставим его в функцию:

|x| = x при x ≥ 0  и  |x| = −x при x < 0
y = f(|x|) = f(x) при x ≥ 0  и  y = f(−x) при x < 0

Значит справа от оси ординат ничего не меняется: там |x| = x, и график совпадает с исходным. А слева значение функции при аргументе −5 равно значению исходной функции при аргументе 5 — то есть левая половина становится зеркальным отражением правой.

Главное. Функция y = f(|x|) всегда чётная: её график симметричен относительно оси ординат. Поэтому левую часть исходного графика в построении вообще не используют — её заменяет отражение правой.
  1. Построить график функции y = f(x).
  2. Удалить часть графика, расположенную левее оси ординат.
  3. Отразить симметрично относительно оси ординат часть графика правее оси ординат.

2. Модуль у всей функции: y = |f(x)|

y = |f(x)| = f(x) при f(x) ≥ 0  и  y = −f(x) при f(x) < 0

Здесь смотрим не на знак аргумента, а на знак самой функции. Всё, что было выше оси абсцисс, остаётся на месте. Всё, что было ниже, отражается наверх.

Главное. График функции y = |f(x)| никогда не опускается ниже оси абсцисс. Точки пересечения с осью абсцисс остаются на своих местах — и превращаются в углы графика.
  1. Построить график функции y = f(x).
  2. Отразить симметрично относительно оси абсцисс часть графика, расположенную ниже оси абсцисс.
  3. Удалить часть графика, расположенную ниже оси абсцисс.

3. Два модуля сразу: y = |f(|x|)|

Порядок действий диктуют сами скобки: сначала работает внутренний модуль, потом внешний.

  1. Построить y = f(x).
  2. Сделать внутренний модуль: получить y = f(|x|) — отражением правой части влево.
  3. Сделать внешний модуль: то, что оказалось ниже оси абсцисс, отразить наверх.

Порядок можно поменять местами и получить тот же результат, но так путаницы меньше: идём изнутри наружу, как при вычислении по формуле.

Проверка ответа в одну секунду. Если в задании был внутренний модуль, а получившийся график несимметричен относительно оси ординат — ошибка. Если был внешний модуль, а часть графика ушла ниже оси абсцисс — тоже ошибка.

5. Сколько получится нулей

Это самый частый вопрос по теме, и он решается без чертежа.

Для y = f(|x|): решаем f(t) = 0 и берём только неотрицательные корни t. Каждый положительный корень даёт два нуля (t и −t), а корень t = 0 — один.

Для y = |f(x)|: количество нулей не меняется вообще, потому что |f(x)| = 0 равносильно f(x) = 0.

|x|² = x², поэтому x² − 4|x| + 3 — это f(|x|) для f(x) = x² − 4x + 3

Приём с |x|² = x² — рабочая лошадка темы: он позволяет увидеть внутренний модуль там, где его на первый взгляд нет.

Проверь себя

Четыре быстрые задачи. Каждую сначала прикидывай на чертеже, потом отвечай. Переключатель действует и здесь, и в самостоятельной работе ниже.

Разобранные примеры

Пример 1. Внутренний модуль: y = x² − 2|x| − 5

Показать решение
1. Так как |x|² = x², функцию можно читать как y = f(|x|), где f(x) = x² − 2x − 5. Значит строим обычную параболу и отражаем её правую часть влево.
2. Ветви вверх (a = 1 > 0). Вершина: x₀ = 2 : 2 = 1, y₀ = 1 − 2 − 5 = −6, то есть (1; −6). Ось симметрии x = 1.
3. Нули: x² − 2x − 5 = 0, D = 4 + 20 = 24, x = 1 ± √6, то есть примерно 3,4 и −1,4. С осью ординат парабола пересекается в точке (0; −5).
4. Удаляем часть левее оси ординат и отражаем туда правую часть.
Результат: график с двумя одинаковыми «ямами» в точках (1; −6) и (−1; −6) и углом в точке (0; −5).
Обрати внимание: точка (0; −5) стала углом — в ней склеились правая часть и её отражение.

Пример 2. Внешний модуль: y = |x² − 2x|

Показать решение
1. Строим параболу y = x² − 2x: ветви вверх, вершина x₀ = 2 : 2 = 1, y₀ = 1 − 2 = −1, то есть (1; −1).
2. Нули: x² − 2x = 0 → x(x − 2) = 0 → x = 0 и x = 2. С осью ординат — точка (0; 0).
3. Часть параболы между нулями лежит ниже оси абсцисс — отражаем её вверх. Вершина (1; −1) переходит в (1; 1).
Результат: «горб» высотой 1 между точками 0 и 2, а по краям — прежние ветви параболы.
Нули 0 и 2 остались на месте и стали углами графика — это верный признак внешнего модуля.

Пример 3. Оба модуля: y = |x² − 6|x| + 4|

Показать решение
1. Функция чётная, поэтому достаточно построить её при x ≥ 0, а потом отразить влево. При x ≥ 0 имеем y = |x² − 6x + 4|.
2. Парабола y = x² − 6x + 4: вершина x₀ = 3, y₀ = 9 − 18 + 4 = −5, то есть (3; −5). Нули: D = 36 − 16 = 20, x = 3 ± √5, примерно 0,8 и 5,2.
3. Отражаем вверх ту часть, что ниже оси абсцисс: вместо ямы (3; −5) получается горб (3; 5).
4. Полученный график отражаем симметрично относительно оси ординат.
Результат: четыре нуля (примерно ±0,8 и ±5,2) и два горба высотой 5 в точках x = 3 и x = −3.

Пример 4. Корень под модулем: y = √|x| − 2

Показать решение
1. Модуль стоит у аргумента, значит это f(|x|) для f(x) = √x − 2.
2. Строим y = √x − 2. Область определения [0; +∞), график начинается в точке (0; −2) и медленно растёт: при x = 4 значение 0, при x = 9 значение 1.
3. Отражаем эту ветвь влево. Область определения новой функции — вся прямая.
Результат: два нуля, x = 4 и x = −4, наименьшее значение −2 достигается при x = 0.

Пример 5. Гипербола под модулем: y = |6 : (x − 1)|

Показать решение
1. Модуль внешний, значит отражаем наверх то, что ниже оси абсцисс.
2. У гиперболы y = 6 : (x − 1) левая ветвь (при x < 1) целиком лежит ниже оси абсцисс — вся она уходит наверх. Правая ветвь остаётся на месте.
Результат: две ветви, обе выше оси абсцисс, вертикальная асимптота x = 1 сохраняется.
Нулей у этой функции нет: дробь нулём не бывает, и модуль этого не меняет.

Самостоятельная работа

Восемь задач. Каждый график строй в тетради: оси, вершина, нули, пунктиром — та часть, которую отражаешь. В поле вводи только ответ. Если совсем не идёт, включи режим «С пропусками» переключателем выше.

Что забрать с урока

1. Модуль у аргумента — зеркало по оси ординат: левое стираем, правое отражаем влево. Результат всегда чётный.

2. Модуль у всей функции — зеркало по оси абсцисс: нижнее отражаем вверх. Результат нигде не ниже оси абсцисс, нули остаются на месте и становятся углами.

3. Два модуля сразу — сначала внутренний, потом внешний.

4. Ключ ко всем задачам на нули: |x|² = x², поэтому x² − 4|x| + 3 — это f(|x|) для f(x) = x² − 4x + 3. Дальше замена t = |x| ≥ 0.

Домашнее задание — отдельная страница по этой же теме: четырнадцать задач с подсказками и полными решениями.
