Памятка: всё, что понадобится

Сюда возвращаются, когда застряли. Читать целиком сразу не нужно.

Пропорция

Что такое пропорция

ab = cd

Равенство двух отношений. Числа a и d — крайние члены, b и c — средние.

Знаменатели не равны нулю — это и есть первое условие ОДЗ.

Основное свойство

a · d = b · c

Произведение крайних членов равно произведению средних — «перемножаем крест-накрест».

Работает только тогда, когда слева и справа стоит ровно по одной дроби.

Число — тоже дробь

4 = 41

Если одна часть уравнения — обычное число, запиши его дробью со знаменателем 1, и пропорция готова.

365x = 4 → 36 · 1 = 4 · 5x.

ОДЗ

Когда писать ОДЗ

Всегда, если в уравнении есть дробь с переменной в знаменателе, корень чётной степени или логарифм.

ОДЗ записывают до решения, а не после.

Знаменатель приравниваем к нулю и запрещаем найденные значения.

Как найти ОДЗ

2x − 1 ≠ 0 = x ≠ 0,5

Каждый знаменатель с переменной даёт своё запрещённое значение.

Если знаменатель — число (например 30), запретов нет.

Ловушка ЦТ

Корень найден правильно, но он совпал с запрещённым значением.

Тогда ответ — нет корней.

Составители тестов подбирают такие примеры специально.

Дробь и переменная

Дробь равна нулю

AB = 0  ⟺  A = 0 и B ≠ 0

Числитель приравниваем к нулю, знаменатель обязан нулю не равняться.

Проверка по ОДЗ здесь обязательна.

Сначала упростить

Если в числителе или знаменателе стоят скобки, раскрой их и приведи подобные — и только потом перемножай крест-накрест.

Иногда после упрощения переменная из знаменателя вообще исчезает.

Выразить переменную

12ab25cx = 4ba

Перемножаем крест-накрест и выражаем нужную букву.

Не перемножай всё сразу — дождись деления, дробь часто сокращается.

Когда дробей много

Три дроби и больше

Крест-накрест здесь не работает: приводим все дроби к общему знаменателю.

Дальше числитель приравниваем к нулю — получается линейное уравнение.

Порядок действий

1. Записать ОДЗ.

2. Привести к одной дроби или перемножить крест-накрест.

3. Решить линейное уравнение.

4. Сверить корень с ОДЗ.

Частые ошибки

Забыть ОДЗ и записать посторонний корень в ответ.

Умножить только первое слагаемое скобки на множитель.

Перемножить крест-накрест, когда дробей три.

1. Пропорция и её основное свойство

ОПРЕДЕЛЕНИЕ
Пропорцией называют равенство двух отношений.
ab = cd
ОСНОВНОЕ СВОЙСТВО
Произведение крайних членов пропорции равно произведению средних. Проще говоря — перемножаем крест-накрест и приравниваем произведения.
a · d = b · c

Пример 1

Решить уравнение 2x = 34.

1. Сразу записываем ОДЗ: в знаменателе стоит x, значит x ≠ 0.
2. Перемножаем крест-накрест: 2 · 4 = 3 · x.
3. Получилось линейное уравнение 3x = 8.
x = 83
Корень 83 не равен нулю, значит ОДЗ он не нарушает — ответ годится.

2. ОДЗ — и почему без него нельзя

ПРАВИЛО
Если в уравнении есть дробь с переменной в знаменателе, корень чётной степени или логарифм — до решения записываем ОДЗ: область допустимых значений.

Для дроби правило одно: знаменатель не равен нулю. Приравниваем каждый знаменатель к нулю и запрещаем найденные значения.

2x − 1 ≠ 0 = x ≠ 0,5
ЛОВУШКА
Составители тестов любят уравнения, у которых корень «случайно» совпадает с запрещённым значением. Если это произошло — корень посторонний, и ответ будет нет корней.

Пример 2

Решить уравнение 0,75(8x − 12) + x − 54x − 8 = 0.

1. ОДЗ: 4x − 8 ≠ 0, значит x ≠ 2.
2. Дробь равна нулю, когда числитель равен нулю: 6x − 9 + x − 5 = 0.
3. Приводим подобные: 7x − 14 = 0, отсюда x = 2.
4. Но x = 2 запрещено по ОДЗ.
Ответ: корней нет
Именно поэтому ОДЗ пишут в начале: иначе двойка спокойно уедет в ответ.

4. Пропорция с многочленами

Крест-накрест работает и тогда, когда в числителях и знаменателях стоят скобки. Главное — не забыть про ОДЗ и аккуратно раскрыть скобки.

Пример 4

Решить уравнение 2(3x + 5)2x − 1 = 3xx + 2.

1. ОДЗ: x ≠ 0,5 и x ≠ −2.
2. Знаменатели общих множителей не имеют, поэтому сразу перемножаем крест-накрест: 2(3x + 5)(x + 2) = 3x(2x − 1).
3. Двойку вносим внутрь первой скобки — во все слагаемые сразу: (6x + 10)(x + 2) = 6x2 − 3x.
4. Раскрываем: 6x2 + 22x + 20 = 6x2 − 3x.
5. Квадраты сокращаются, остаётся 25x = −20.
x = −0,8
Корень не совпал ни с 0,5, ни с −2 — ответ подходит.
ИНОГДА СНАЧАЛА УПРОЩАЮТ
Если в числителе и знаменателе стоят скобки, раскрой их и приведи подобные — дробь может заметно упроститься, и только потом перемножай крест-накрест.

Пример 5

Решить уравнение 2(x + 3) − 3(2x − 1)2(6x − 1) − 4(3x − 2) = 3(2x + 1) − (5x + 2)4(3x + 2) − 3(4x + 2).

1. Упрощаем слева: числитель 2x + 6 − 6x + 3 = 9 − 4x, знаменатель 12x − 2 − 12x + 8 = 6.
2. Упрощаем справа: числитель 6x + 3 − 5x − 2 = x + 1, знаменатель 12x + 8 − 12x − 6 = 2.
3. Получилась простая пропорция 9 − 4x6 = x + 12.
4. Крест-накрест: 18 − 8x = 6x + 6, отсюда −14x = −12.
x = 67
Знаменатели после упрощения стали числами — значит ОДЗ здесь не нужно.

5. Дробь, равная нулю

УСЛОВИЕ
Дробь равна нулю тогда и только тогда, когда её числитель равен нулю, а знаменатель нулю не равен.
AB = 0  ⟺  A = 0  и  B ≠ 0

Пример 6

Решить уравнение 3(x − 1) − 62x + 1 = 0.

1. ОДЗ: 2x + 1 ≠ 0, значит x ≠ −12.
2. Числитель равен нулю: 3x − 3 − 6 = 0, отсюда 3x = 9 и x = 3.
3. Тройка запрету не противоречит.
x = 3
Если бы получилось x = −0,5, ответом было бы «корней нет».
КОГДА ОДЗ НЕ НУЖНО
Если в знаменателе нет переменной, запретов нет: уравнение равносильно обычному уравнению «числитель = 0».
4(x − 2) − 65 = 0 = 4(x − 2) − 6 = 0

6. Выразить переменную из пропорции

Приём тот же — крест-накрест, но в ответе остаются буквы.

Пример 7

Выразить x из пропорции 12ab25cx = 4ba.

1. Перемножаем крест-накрест: 12ab2 · a = 4b · 5cx.
2. Слева получаем 12a2b2, справа 20bcx.
3. Делим обе части на 20bc — и только теперь сокращаем.
x = 12a2b220bc = 3a2b5c
Не перемножай всё сразу в одну строку: дождись деления, дробь почти всегда сокращается.

7. Дробно-рациональные уравнения, сводящиеся к линейным

ВАЖНО
Когда дробей три и больше, крест-накрест не работает. Приводим все дроби к общему знаменателю.

Пример 8

Решить уравнение x + 22 − x + 35 = x + 13.

1. Переносим всё влево: x + 22 − x + 35 − x + 13 = 0.
2. Общий знаменатель 30. Дополнительные множители: 15, 6 и 10.
3. Собираем в одну дробь: 15(x + 2) − 6(x + 3) − 10(x + 1)30 = 0.
4. Знаменатель — число 30, нулю он не равен, значит достаточно приравнять к нулю числитель.
5. Раскрываем скобки: 15x + 30 − 6x − 18 − 10x − 10 = 0.
6. Приводим подобные: −x + 2 = 0.
x = 2
Проверка: 42 − 55 = 2 − 1 = 1 и 33 = 1. Сошлось.
